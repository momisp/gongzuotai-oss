# 视频替换工作台 · 使用说明书

> 这是**界面怎么点**的说明。业务长流程（定妆→切段→送方舟→拼轨）仍看「流程说明」。

---

## 一分钟上手

1. 左侧点项目（如「琵琶曲」）
2. 顶部四个场景按钮二选一开工：
   - **① 分镜对照审核（闸门1）**：逐段看原片 vs 生成段，点分类
   - **② 送方舟包复查（闸门2）**：逐包复查，确认后再送方舟
3. **左边看视频不丢**；**右边改材料**；切段只换画面，不用整页乱滚
4. 改完点底部 **「保存并确认闸门1」** / **「确认包已审」**（自动保存草稿 ≠ 过闸门）

## 界面长什么样

```
顶栏：项目状态 / 进度 / 复位
Stepper：①分镜审 ②送方舟审 ③全片验收 ④素材 | 均衡·视频最大化·面板优先 | 项目栏
┌─────────────────────────┬──────────────────────┐
│ 左 STAGE（视频常驻）      │ 右 CONTEXT（当前段材料）│
│ 左参考片 | 右生成对照     │ 档案 / 判定 / 列表     │
│ 播放条 + 段时间轴         │ 底部常驻操作按钮       │
└─────────────────────────┴──────────────────────┘
下方「更多」：总览 / 定妆照 / 原片 / 成片 / 报告 / 日志
```

| 区域 | 干什么 |
|------|--------|
| 左 STAGE | 一直能看见视频；上一段/下一段、倍速、同步、自动续播 |
| 右 CONTEXT | 当前段表单；随场景变；底栏按钮不跟着滚走 |
| 段时间轴 | 彩条 = 各段；点一下跳到那段 |
| 布局按钮 | 均衡 / 只看视频 / 面板优先；`\`、`Shift+\`、`Ctrl+B` |

## 四个场景怎么用

### ① 分镜对照审核（闸门1）— 日常最常用

| 步骤 | 操作 |
|------|------|
| 1 | 左看「分镜原片」，右看「生成段」（缺生成会显示占位） |
| 2 | 右侧点人工判断：**角色一 / 角色二 / 双人同镜 / 空镜**（点一下即生效，约 0.8s 自动保存） |
| 3 | 有问题就填问题类型/说明，可勾「问题段」进重跑队列 |
| 4 | ←→ 或「上一段/下一段」继续；可开「自动续播」 |
| 5 | 全部审完 → **「保存并确认闸门1」**（不过闸门不能拼包） |

**批处理**：筛好分类后，顶部「将筛出的 N 段统一改判」可一次改多段。

### ② 送方舟包复查（闸门2）

| 步骤 | 操作 |
|------|------|
| 1 | 先在 ① 过闸门1，再点「按人工判断拼包」 |
| 2 | 左=参考包，右=生成对照；点 parts 会跳到包内该段 |
| 3 | QA 点选：可用 / 朝向错误 / 换景 / 敏感 / 肖像化 |
| 4 | 要改参侧重送：点「重送」→ 内联抽屉 → 入队（不是立刻跑） |
| 5 | 逐包看完 → **「确认包已审」** → **「送方舟生成」** |

顶部红/黄告警：覆盖不完整或闸门未过时会挡住送方舟（`force` 旁路仅特殊情况用）。

### ③ 全片对照验收

- 左=原片全片，右=成片（右侧可切换版本）
- 勾验收清单（表情/朝向/手部/运镜/换景）— 仅本机记录
- 满意后点 **「设为基线」**

### ④ 素材浏览

- 单播放器；右侧网格选定妆照 / 原片 / 成片
- 原片/成片可「设为 S3 对照右片」

## 常用按钮与状态

| 你看到的 | 含义 / 怎么办 |
|----------|----------------|
| 已中断 / ARK_SEND_PARTIAL | 送方舟中途断了；可点「任务卡住了？点此复位」再重送失败包 |
| 已自动保存 · 时刻 | 草稿已写盘；**还没过闸门** |
| 闸门1 × | 还不能拼包 → 去 ① 确认 |
| 闸门2 × | 还不能送方舟 → 去 ② 确认 |
| 另起页面 | 新浏览器标签打开本工作台（更大、少被侧栏挤） |

---

## 快捷键

| 键 | 作用 |
|----|------|
| `←` / `→` | 上一段 / 下一段 |
| `\` | 视频最大化 ↔ 均衡 |
| `Shift+\` | 面板优先 ↔ 均衡 |
| `Ctrl+B` / `⌘B` | 收起/展开左侧项目栏 |

---

## 推荐工作节奏（琵琶曲等现有项目）

1. 另起页面 → 选项目  
2. ① 逐段改判（可开自动续播）→ 确认闸门1  
3. ② 拼包 → 逐包 QA → 确认闸门2 → 送方舟  
4. 若部分失败：复位后只重送失败包，或重送抽屉入队  
5. ③ 全片对照 → 设基线  

「更多」里的流程说明 = 制作规范长文；本说明书 = 这个两栏界面怎么用。
