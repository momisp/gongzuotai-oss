## 1. 一句话定位

**个人工作台**是面向测试工程师的本机一站式工作壳：以「项目」为中心，把测点设计、数据验证、远程装包、冒烟/功能测试、业务自动化、运维巡检、甘特排期、知识笔记和禅道用例导入，串成「选项目 → 干活 → 留证据 → 给结论」的闭环。

---

## 2. 要解决什么问题

测试日常工作里，工具往往分散在多处：

| 痛点 | 工作台怎么解 |
|------|----------------|
| 入口散、上下文丢 | 统一侧栏 +「今日工作台」记住最近/置顶项目 |
| 测点写完不好进禅道 | 测点生成后可导出 / 同步导入禅道 CSV |
| 装包、冒烟、结论割裂 | 项目中心串联测点 → 装包 → 冒烟/功能测 → 本轮结论 |
| 运维巡检靠手工拼日报 | 一键每日巡检（ECS + 证书等）并留报告 |
| 知识与踩坑难检索 | QA 问题集 + 测试/前后端知识手册，支持全局搜索 |

**不做的事（边界）**

- 不做公网多租户 SaaS、不做统一账号体系  
- 不替代禅道缺陷库（结论与缺陷模板可本地留档，再贴禅道）  
- 不以移动端为首要适配目标  

---

## 3. 目标用户与成功标准

| 角色 | 典型场景 | 成功标准 |
|------|----------|----------|
| 测试工程师（主用户） | 上班打开工作台，继续某项目冒烟/回归 | 约 30 秒内回到「当前项目 + 下一动作」 |
| 测试工程师 | 测点 → 装包 → 跑冒烟 → 写结论 | 同一项目上下文可跳转，结论可回看 |
| 测试侧运维 | 每日巡检、证书到期、看 ECS | 一键能出日报报告 |
| 本机维护者 | 嵌入页异常、服务未起 | 健康检查可区分工作台 / 测点服务 / ADB 状态 |

业务侧重：游戏相关业务线常见场景（如 OA / 商务 / 会长 / SDK / 充值分佣等主流程与造数），详见《业务自动化需求》。

---

## 4. 产品原则

1. **项目优先**：一切重要动作尽量带上当前项目上下文。  
2. **闭环优先**：少堆新工具，先把「设计 → 执行 → 证据 → 结论」跑通。  
3. **本机优先**：数据落在本地 `data/`，密钥不进仓库。  
4. **可交接**：对外协作以禅道为准；工作台负责提效与留档，不抢缺陷管理主阵地。

## 6. 功能模块说明

### 6.1 今日工作台

- 展示最近项目、置顶项目卡片  
- 快捷：项目中心 / 远程装包 / 运维 / 业务自动化  
- 服务健康与一键自检（工作台、测点相关服务、ADB 等）  
- 记住上次页面与项目，支持「继续上次」  

### 6.2 项目中心 & 项目资产

**项目中心**

- 项目增删改查，关联资产与甘特排期  
- 「本轮测试」：跳转测点 / 装包 / 冒烟 / 功能测  
- 本轮结论留档（通过 / 阻塞 / 未通过 / 进行中 + 备注）  
- 缺陷描述模板一键复制（便于贴禅道）  
- 发版前功能/性能/安全勾选清单  
- 装包历史、回归建议（可结合甘特未完成任务）  

**项目资产**

- 按项目管理文档、包、XMind、链接等  
- 上传 / 预览；XMind 等可导入测点会话  
- 资产可一键带到「测试点生成」或「数据验证」  

### 6.3 设计用例

| 模块 | 能力摘要 |
|------|----------|
| 测试点生成 | 按项目上下文生成测点：① 框架（冒烟）② 业务场景 ③ 页面功能 ④ 专项（权限/并发/弱网/兼容/安全）；可评审、导出；支持导入禅道（模块层级：冒烟 / 场景 / 功能测试 / 专项） |
| 数据验证 | 数据/验算类工作台（嵌入敏捷模拟能力） |
| 测试报告生成 | 按模板填字段，输出 Markdown（测试报告 / 性能报告 / Bug 率统计等） |

### 6.4 执行装包（测试脚本工具）

- **远程装包**：安卓 ADB / iOS；装包、投屏、传文件；历史按项目归档  
- **充值回调模拟**：便于支付相关联调  
- **Excel → 禅道用例**、**XMind → CSV**  
- 打开脚本目录、快捷 CLI 入口  

### 6.5 自动化

**业务自动化**

- Playwright / Airtest 等模块入口  
- 跨端主流程台、角色台、造数脚本  
- 业务冒烟 / 页面功能测试台（截图与运行记录可回看）  
- 可与测点同步到 Playwright 相关流程（按现有实现）  

**压测工具**

- 集成历史压测报告与工具入口  

### 6.6 运维与排期

| 模块 | 能力摘要 |
|------|----------|
| 测试运维工作区 | 一键每日巡检报告、组内 ECS 明细、证书到期巡检 |
| 甘特图排期表 | 多项目排期与拖拽；可对接禅道执行信息；项目可关联排期并产出回归建议 |
| 运维监控指标 | 独立桌面壳打开云控制台类页面 |
| 静态工具网站 | JSON / Base64 / 时间戳 / 哈希等开发小工具集合 |

### 6.7 知识与系统效率

- **QA 问题集**：踩坑与解法笔记，可检索  
- **测试信息**：测试 / 前端 / 后端 / 课程等知识手册  
- **系统**：文件路径收藏、常用网址、数据转换、历史复制、区域录屏、延时摄影、CPU 监控、微信链接申诉等  
- **休闲**：解压小游戏（独立桌面窗口）、壁纸、AI Story（本地部署后进入）  

### 6.8 其他集成

- **敏捷模拟平台**：多角色流水线演示/练习；测点与数据验证为其嵌入形态  
- **Game Notes Web**：游戏笔记类独立前端应用

## 7. 核心用户旅程

### 旅程 A：上班续测

打开今日工作台 → 选最近/置顶项目 → 进入测点、装包、运维或项目详情 → 可恢复上次路由。

### 旅程 B：一轮测试闭环

项目中心 → 测点设计 → 远程装包 → 冒烟/功能测 → 保存本轮结论 →（可选）复制缺陷模板贴禅道。

### 旅程 C：测点进禅道

带项目上下文打开测试点生成 → 产出 ①②③④ → 导出禅道 CSV 或登录同步模块并导入。

### 旅程 D：装包与真机

测试脚本 → 远程装包 → 选设备 → 装包/投屏 → 装包历史写入当前项目。

### 旅程 E：业务主流程 / 造数

业务自动化 → 选业务线与步骤 → 跑 Playwright/主流程/造数 → 查看运行记录与截图。

### 旅程 F：排期与回归

甘特维护任务 → 关联项目 → 项目内查看未完成任务对应的回归建议 / 发版勾选清单。

### 旅程 G：运维日报

运维工作区 → 一键生成每日巡检 → 查看报告；需要时打开监控壳看控制台。

## 8. 与禅道的关系

| 工作台负责 | 禅道负责 |
|------------|----------|
| 测点设计、用例结构化导出 | 用例库、执行记录主库 |
| 本轮结论、缺陷模板草稿 | 正式缺陷单与流转 |
| 甘特排期辅助、回归建议 | 迭代/执行任务（可对接） |

导入约定（测点 → 禅道模块）：

```
冒烟测试
业务场景 / …
功能测试
  └ 首页 / 商城 / 我的 / …
专项测试 / …
```

## 9. 技术形态（给协作者的高层说明）

| 层 | 技术 | 说明 |
|----|------|------|
| 主壳 | Flask + 模板 + 原生 JS | 端口 **8765**，`workbench/` |
| 测点 / 数据验证 | Vite + React + Node API | `integrated/agile-sim-demo`，工作台反向代理嵌入 |
| 其他集成 | 静态页 / Electron / Pygame 等 | 甘特、工具小站、监控壳、解压游戏等 |
| 数据 | 本地 `data/*.json` 与运行产物目录 | 含密钥的配置从 `*.example.json` 复制，勿提交 |

**部署约束**：仅本机使用；请勿把真实密码、Token、数据库账号推到远程仓库。

## 10. 数据与资产（概念层）

对外协作时只需理解「本地落盘、按项目归档」：

- 项目与资产、本轮结论、发版清单、装包历史  
- 测点 / 数据验证会话记录  
- 甘特索引与运维报告  
- 自动化 / 冒烟运行记录与截图目录  
- 可选：`data/backups/` 手动备份  

细节文件清单见仓库 `data/` 与《API-配置契约》。

| 类别 | 要求 |

## 13. 演示建议（拿给别人看时）

建议 8～10 分钟 Demo 路径：

1. 打开今日工作台，展示项目卡片与健康状态  
2. 进入某一项目 → 本轮测试区块  
3. 打开测试点生成（带项目）→ 展示四步结构与预览  
4. 说明禅道导出模块结构（冒烟 / 场景 / 功能 / 专项）  
5. 远程装包或业务自动化任选其一跑通留证  
6. 回到项目写一条本轮结论 + 复制缺陷模板  
7. （可选）运维一键巡检或甘特排期一眼带过
