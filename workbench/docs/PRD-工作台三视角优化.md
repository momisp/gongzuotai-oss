## 1. 背景与目标

个人工作台已具备项目中心、测试点生成、远程装包、业务自动化、运维巡检、QA 问题集、测试信息等能力，能支撑日常测试，但存在：

- **测试侧**：工具多、链路断，缺少「按项目推进一轮测试」的闭环。
- **工程侧**：大前端/嵌入页偶发白屏，多服务耦合，诊断成本高。
- **体验侧**：入口偏工具橱窗，心智负担重，失败时不知下一步。

**目标**：少加新工具，把现有能力收成「选项目 → 干活 → 留证据 → 给结论」；同时提升稳定性与可用性。

**非目标（本期不做）**：重做设计系统、移动端适配、统一账号体系、替换禅道为自建缺陷库。

## 2. 用户与场景

| 角色 | 典型场景 | 成功标准 |
|------|----------|----------|
| 测试工程师 | 上班打开工作台，继续某项目冒烟/回归 | 30 秒内回到「当前项目 + 下一动作」 |
| 测试工程师 | 测点生成后装包、跑冒烟、写结论 | 同一项目上下文可跳转，结论可留档 |
| 开发维护者 | 嵌入页白屏 / 端口未起 | 有错误边界与健康检查，可自助重启/复制日志 |
| 普通使用者 | 找入口、搜索笔记/项目 | 侧栏按工作流分组，全局搜索可用 |

## 4. 方案概要

### 4.1 信息架构（侧栏）

```
今日工作台        ← 新首页（QA-01 / UX-02）
项目
  ├ 项目中心
  └ 项目资产
设计用例
  ├ 测试点生成
  └ 数据验证
执行装包
  └ 测试脚本工具（装包 / 回调等）
自动化
  └ 业务自动化
运维
  ├ 测试运维工作区
  └ 甘特图排期表
知识
  ├ QA 问题集
  └ 测试信息
系统
  ├ 常用网址 / 路径收藏 / 转换工具 …
  └ 休闲（解压小游戏等）
其他（低频 integrated）
```

### 4.2 「今日工作台」首页卡片（示意）

每个最近项目卡片包含：

- 项目名、最近迭代/别名
- 快捷：打开测点 · 远程装包 · 运维 · 项目详情
- 可选摘要：关联资产数、最近测点会话、排期状态（有则显示）

顶部保留少量全局快捷（运维、装包），不再平铺全部工具。

### 4.3 测试闭环（最小版）

在**项目中心详情**增加「本轮测试」区块：

1. 入口：跳转测点生成（带 projectId）
2. 入口：跳转远程装包（带项目上下文，能带则带）
3. 结论表单：通过 / 阻塞 / 备注 / 时间；写入项目本地数据（如 `projects.json` 扩展字段或独立 `data/project_round_results.json`）
4. 列表展示最近几轮结论，便于日报/复盘

缺陷模板（QA-04）可二期：从自动化失败 JSON/截图路径拼 Markdown。

### 4.4 健康检查与错误边界

- 新页或首页底部：「服务状态」：工作台 API、agile-sim Vite/API、ADB `devices` 摘要。
- 嵌入 iframe / React 根：捕获渲染错误，展示「刷新嵌入 / 打开独立窗口 / 复制错误信息」。
- 启动日志继续打印真实 `AGILE_SIM_DIR` 解析路径。

### 4.5 工程拆分策略

- 不一次性重写：按域抽出 `static/modules/*.js`，`app.js` 保留引导与 `navigate`/`openTool`。
- 优先拆：`adb`、`projects`、`test-info`、`ops`（近期改动热区）。

## 5. 里程碑

| 里程碑 | 范围 | 验收 |
|--------|------|------|
| **M0 基线** | 现有功能 git 提交并推送；本 PRD 入库 | 远程可见基线 tag/commit |
| **M1 稳定 + 导航** | DEV-01、DEV-02、UX-01、UX-02、QA-01 | 首页为项目卡片；侧栏分组；健康检查可用；嵌入错误不整页白死 |
| **M2 测试闭环** | QA-02（最小）、UX-04、UX-05 | 项目内可记本轮结论；失败态三按钮 |
| **M3 工程加固** | DEV-03、DEV-04、DEV-06 | app.js 热区拆分；路径校验；备份入口 |
| **M4 增强** | QA-03～07、UX-03/06、DEV-05/07/08 | 按需排期，不强行一次做完 |

**建议开工顺序**：先做 M1（首页项目卡片 + 健康检查/错误边界 + 侧栏分组），与此前「性价比最高 5 件」中的 1、3、4 对齐。

## 7. 风险与约束

| 风险 | 缓解 |
|------|------|
| `app.js` 过大，拆分易引入全局函数依赖问题 | 先抽纯函数/API，再搬 UI；每拆一块做手动点击验收 |
| agile-sim 为 junction，改动路径易混淆 | DEV-04 启动打印真实路径；PR 说明编辑目录 |
| 本地 `data/` 含个人环境数据 | 密钥类继续 gitignore；提交前人工检查 |
| Flask 非 debug，改后端需重启 | 文档与健康页提示「需重启工作台」 |
