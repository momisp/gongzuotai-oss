# 浏览器与联调

## DevTools 每天用这三块

| 面板 | 干什么 |
|------|--------|
| Elements | 看结构、改样式试错、找选择器 |
| Console | 看报错、临时执行表达式 |
| Network | 看请求 URL、状态码、响应体、耗时 |

## 联调检查清单

- [ ] 请求方法对不对（GET/POST）  
- [ ] 状态码：200 成功；401 登录；404 路径；500 后端  
- [ ] 请求头是否带了 token  
- [ ] 响应 JSON 字段名是否和页面取值一致  
- [ ] 跨域报错时：是浏览器拦的，还是服务没配 CORS  

## 小工程

- 安装 Node LTS → `npm create vite@latest` 选 React 或 Vue  
- `npm install` → `npm run dev` → 浏览器打开本地地址  

## 和测试的交集

- 稳定定位：优先 role/label/testid，少用易变 XPath  
- 失败时先看 Console + Network，再开测工具
