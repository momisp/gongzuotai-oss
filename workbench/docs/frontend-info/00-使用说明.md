# 前端知识 · 使用说明

面向「想从前端 0 到能干活」的查阅区。资料来自：

1. **本目录精编手册**（完整学习路径与分块要点）
2. **网络公开文档**（MDN、React、Vue、Playwright 等，见外部链接）
3. **可选本地目录**（配置 `frontend_root` 后点「重建前端索引」）

本地未单独找到「前端学习用」文件夹时，以本手册 + 网络为主；练手可对照工作台里的 React 嵌入页（`integrated/agile-sim-demo`）。

## 怎么用

1. 测试信息 → 左侧点 **前端知识**
2. 先打开 `01-前端知识学习目录.md`，按 L0→L5 学
3. 上方可按阶段筛选
4. 有本地课件/笔记目录时：写入配置 `frontend_root` →「重建前端索引」
