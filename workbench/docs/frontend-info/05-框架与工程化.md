# 框架与工程化

## 先选一条主线

| 主线 | 适合 | 官方入口 |
|------|------|----------|
| React | 与本工作台嵌入页相近 | https://react.dev/learn |
| Vue 3 | 模板好上手、国内资料多 | https://cn.vuejs.org/ |

**不要**入门阶段 React + Vue + Angular 一起学。

## 框架阶段共同目标

1. 组件拆分（按钮、表格行、弹窗）  
2. 列表渲染与表单受控  
3. 路由切换两个以上页面  
4. 请求数据：loading / 空 / 错 三态  
5. 用 Vite（或官方脚手架）本地跑起来  

## 工程化最低认知

- `package.json` 脚本：`dev` / `build`  
- 依赖装在 `node_modules`，不要手改里面的代码  
- 环境变量：区分本地 API 地址与线上  

## 实战建议

- 选题：待办、简单后台列表、对接自己 FastAPI 的「文章列表」  
- 对照工作台：`integrated/agile-sim-demo` 看 React 组件怎么拆（只读学结构即可）
