# HTML 与 CSS 要点

## HTML 先记住这些

- 结构：`html / head / body`
- 内容：标题 `h1~h6`、段落 `p`、列表 `ul/ol`、链接 `a`、图片 `img`
- 表单：`form`、`input`、`select`、`textarea`、`button`、`label`
- 语义：能用 `button` 就不用 `div` 点击；区块用 `header/main/nav/footer`

## CSS 最小可用集

| 主题 | 要会 |
|------|------|
| 选择器 | 标签、class、后代；少用杂乱 id 样式 |
| 盒模型 | width/height、margin、padding、border |
| 布局 | **Flex**：主轴、换行、对齐 |
| 文字 | font-size、color、line-height |
| 状态 | `:hover`、禁用态样式 |

## 练习题（做完再进 JS）

2. 一个两列布局：左侧菜单 + 右侧内容  
3. 窄屏时菜单变顶栏（媒体查询即可）
