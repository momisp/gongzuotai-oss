# 前端知识学习目录（普通人 0→1）

和「测试知识」「后端知识」一样：按层学，学完一层再进下一层。  
资料 = **本手册** + **网络官方文档**（+ 可选本地目录）。

## 你在学什么（一句话）

```
HTML 搭结构 → CSS 做样子 → JavaScript 做行为
 → 懂浏览器与 HTTP → 用框架做页面 → 会和后端联调
```

---

## 层级总览

| 层级 | 定位 | 体感时间 | 学完能干什么 |
|------|------|----------|--------------|
| L0 | 认知 | 2～3 天 | 说清前端职责、和后端怎么配合 |
| L1 | HTML + CSS | 2～4 周 | 能切一个静态页面（布局/响应式入门） |
| L2 | JavaScript | 3～6 周 | 会改 DOM、事件、请求接口、处理 JSON |
| L3 | 浏览器与工程入门 | 1～2 周 | 会用 DevTools；会 npm 跑起一个项目 |
| L4 | 框架（React 或 Vue 选一） | 1～2 月 | 能做列表/表单/路由的小中台页 |
| L5 | 联调与进阶 | 持续 | 鉴权联调、组件化、性能/无障碍入门 |

**建议**：先 L0→L2 打牢（不急着上框架）；框架 **React / Vue 二选一** 深挖，不要同时入门。

测试同学加分：L2 的 DOM/事件 + L3 DevTools，对写定位、做前端测试很有帮助。

---

## L0｜认知：前端是干什么的

| 学什么 | 学到什么程度 |
|--------|--------------|
| 浏览器里发生了什么 | 打开 URL → 下载 HTML/CSS/JS → 渲染页面 |
| 前端 vs 后端 | 界面与交互 vs 数据与业务规则 |
| 常见产物 | 官网、后台管理系统、H5、小程序（概念区分） |
| 和测试的关系 | 元素、文案、状态、接口错误都会反映在页面上 |

**学完标准**：能画出「浏览器 ↔ 前端资源 ↔ 后端 API」关系。

**网络**：[MDN 学习区首页](https://developer.mozilla.org/zh-CN/docs/Learn_web_development)

## L1｜HTML 与 CSS 基础

| 学什么 | 学到什么程度 |
|--------|--------------|
| HTML 语义标签 | 标题、段落、列表、表单、链接、图片 |
| 表单控件 | input/select/button、label、必填 |
| CSS 选择器与盒模型 | margin/padding/border、display |
| 布局 | Flex 为主；Grid 了解 |
| 响应式入门 | 媒体查询、移动端大致适配 |

**学完标准**：独立做出「登录页 + 列表页」静态稿（可先不用 JS）。

**手册**：`02-HTML与CSS要点.md`  
**网络**：

- [MDN · HTML](https://developer.mozilla.org/zh-CN/docs/Web/HTML)
- [MDN · CSS](https://developer.mozilla.org/zh-CN/docs/Web/CSS)
- [Flexbox 蛙 Froggy](https://flexboxfroggy.com/#zh-cn)（游戏练 Flex）

## L2｜JavaScript 核心

| 学什么 | 学到什么程度 |
|--------|--------------|
| 语法 | 变量、函数、数组/对象、条件循环 |
| DOM | querySelector、改文本/类名、创建节点 |
| 事件 | click/input/submit；事件委托概念 |
| 异步 | Promise、async/await、fetch 调接口 |
| JSON | 解析与展示列表数据 |
| 调试 | `console`、断点、看报错栈 |

**学完标准**：静态列表页改成「从接口（或 mock JSON）拉数据渲染」；表单提交能 `preventDefault` 并校验。

**手册**：`03-JavaScript要点.md`  
**网络**：

- [MDN · JavaScript 指南](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Guide)
- [javascript.info（现代教程）](https://zh.javascript.info/)
- [MDN · fetch](https://developer.mozilla.org/zh-CN/docs/Web/API/Fetch_API/Using_Fetch)

## L3｜浏览器、网络与小工程

| 学什么 | 学到什么程度 |
|--------|--------------|
| DevTools | Elements / Network / Console 会用 |
| HTTP 与前端 | 状态码、Header、Cookie；看 XHR/fetch |
| 跨域概念 | 为何本地调不通、CORS 是什么（会描述即可） |
| Node / npm | 会 `npm create`、安装依赖、`npm run dev` |
| Git 基础 | clone / commit / push（协作最低要求） |

**学完标准**：能对着 Network 面板说出某个按钮触发了哪次请求、成功还是失败。

**手册**：`04-浏览器与联调.md`  
**网络**：

- [MDN · HTTP](https://developer.mozilla.org/zh-CN/docs/Web/HTTP)
- [Chrome DevTools 概览](https://developer.chrome.com/docs/devtools)

## L4｜框架与工程化（选一条主线）

### 路线 A：React（与本工作台嵌入页技术相近）

| 学什么 | 学到什么程度 |
|--------|--------------|
| 组件与 JSX | 拆按钮/列表/表单 |
| state / props | 数据驱动界面 |
| 列表 key、条件渲染 | 常见列表页 |
| 路由 | 多页面切换 |
| 请求与加载态 | loading / 空态 / 错误态 |

**网络**：[React 官方文档](https://react.dev/learn) · [Vite](https://vitejs.dev/guide/)

| 学什么 | 学到什么程度 |
|--------|--------------|
| 模板与指令 | v-if / v-for / v-model |

| 组合式 API 入门 | ref/reactive 基本用法 |

**网络**：[Vue 官方中文文档](https://cn.vuejs.org/guide/introduction.html)

**学完标准**：完成一个「登录假页 + 列表 CRUD（可 mock）」的小项目。

**手册**：`05-框架与工程化.md`

## 推荐学习顺序

```
L0 认知
 → L1 HTML + CSS（先做出静态页）
 → L2 JavaScript（让页面动起来、会 fetch）
 → L3 DevTools + npm 小工程
 → L4 React 或 Vue（只选一个）
 → L5 联调真实接口 + 清单式打磨
```

**最小就业向路径**：L1 → L2 → L4（其一）→ 会联调列表接口。
