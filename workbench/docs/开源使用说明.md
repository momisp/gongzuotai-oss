# 工作台开源使用说明

给测试同事用的精简指引。本地凭据不要进 Git。

## 1. 克隆与启动

```bash
git clone https://github.com/momisp/gongzuotai-oss.git
cd gongzuotai-oss
python -m pip install -r requirements.txt
# 按本机环境复制示例配置
copy data\game_sdk_config.example.json data\game_sdk_config.json
copy data\money_settlement_config.example.json data\money_settlement_config.json
copy data\adb_config.example.json data\adb_config.json
copy data\v1_regression_biz_config.example.json data\v1_regression_biz_config.json
copy data\gantt_project_index.example.json data\gantt_project_index.json
copy data\project_assets.example.json data\project_assets.json
copy data\links.example.json data\links.json
copy data\projects.example.json data\projects.json
# 编辑上述 json，填入本机测试环境；真实业务链接勿回传 Git
python workbench/app.py
```

浏览器打开控制台（默认端口见启动日志，常见 `8765`）。

## 2. 必改配置

| 文件 | 用途 |
|------|------|
| `data/v1_regression_biz_config.json` | 新商务 v1 回归写门禁 / OA·SW 账号 / 复用层级 |
| `data/money_settlement_config.json` | 结算链路会长/总后台 |
| `data/game_sdk_config.json` | SDK 造数 |
| `data/adb_config.json` | ADB / scrcpy 本机路径 |
| `data/gantt_project_index.json` | 排期表 / 原型链接（仅本机） |
| `data/project_assets.json` / `links.json` / `projects.json` | 项目资产与收藏链接（仅本机） |
| `workbench/.env` | `OPEN_API_KEY` 等，参考 `.env.example` |

写操作前确认 `writeEnabled=false` 能预演；确认无误再开写。

## 3. 环境变量（工具脚本）

`workbench/tools/v1_regression_*.py` 读：

- `SW_API_BASE`
- `SW_ADMIN_USER`
- `SW_ADMIN_PASSWORD`
