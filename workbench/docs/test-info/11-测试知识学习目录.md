# 测试知识学习目录（普通人可按序学）

一份**从零到能独立干活**的知识地图：按顺序学，学完一层再进下一层。  
资料来源 = **本地（手册/课件）** + **网络（公开文档/课程/清单）**，两边对照用。

## 先说结论：要学多少？

| 层级 | 大概定位 | 知识体量（体感） | 能干什么 |
|------|----------|------------------|----------|
| L0 认知 | 知道测试是干什么的 | 1～2 周 | 看懂提测、会提简单问题 |
| L1 手工能干活 | 功能测试主力 | 1～3 个月 | 独立测一个 Web/App 模块 |
| L2 会设计会协作 | 合格测试工程师 | 再 3～6 个月 | 写用例、跟迭代、出结论 |
| L3 会接口与数据 | 偏技术向测试 | 再 3～6 个月 | 抓包、接口测、查库验数 |
| L4 会自动化/专项 | 进阶 / 专项 | 持续积累 | 自动回归、性能或安全入门 |
| L5 体系与质量 | 资深 / 负责人向 | 多项目沉淀 | 策略、风险、流程、带人 |

**普通人建议**：先把 **L0→L2** 走扎实，再按岗位选 L3/L4。

### 有没有像 MDN「学习区」那样的测试网站？

有，但**没有单一官方站包办一切**。最接近「成体系学习区」的是这些（均可在外部链接打开）：

| 站点 | 像不像 MDN | 适合 | 地址 |
|------|------------|------|------|
| **Ministry of Testing（MoT）** | ⭐⭐⭐⭐ 社区课+学习路径 | 入门认知、现代测试思维 | https://www.ministryoftesting.com/ |
| **MoT 入门课** | ⭐⭐⭐⭐ 零基础导论 | L0：开发与测试是什么 | https://www.ministryoftesting.com/courses/essentials-introduction-to-software-development-and-testing |
| **Test Automation University** | ⭐⭐⭐⭐⭐ 免费分课、可刷完 | L4 自动化（Web/API/工具） | https://testautomationu.applitools.com/ |
| **ISTQB + Glossary** | ⭐⭐⭐⭐ 国际大纲/术语（偏教材） | L0～L2 术语与原则 | https://www.istqb.org/ · https://glossary.istqb.org/ |
| **roadmap.sh QA** | ⭐⭐⭐ 一张图看路径 | 总览「还该学什么」 | https://roadmap.sh/qa |
| **OWASP** | ⭐⭐⭐⭐ 安全专项「学习区」 | L4 安全 | https://owasp.org/www-project-top-ten/ |

**怎么选：**

- 想像 MDN 一样**按课点开学**：优先 **Test Automation University**（自动化）+ **MoT Courses**（测试认知）  
- 想像 MDN 一样**查标准说法**：用 **ISTQB Glossary**  
- 只要一张**路线图**：打开 **roadmap.sh/qa**  
- 中文短路径：继续用本手册 L0→L5，网络站当「外链加深」

下面每层都写了：**本地对照** + **网络推荐**。

## 怎么用这份目录

1. 按 L0→L5 顺序学，达「学完标准」再进下一层  
2. 先看本地手册建立中文框架，再用网络资料加深 / 查原文

## L0｜入门认知（建立地图）

**目标**：明白测试在软件交付里扮演什么角色。

| 序号 | 学什么 | 学到什么程度 |
|------|--------|--------------|
| 0.1 | 软件是怎么做出来的 | 能画出需求→开发→测试→上线 |
| 0.2 | 测试是干什么的 / 不是干什么的 | 测通≠无 bug；测是风险控制 |
| 0.3 | 常见测试类型名词 | 功能 / 兼容 / 性能 / 安全 / 冒烟 / 回归 |
| 0.4 | 缺陷怎么描述 | 现象、步骤、预期、实际 |

**学完标准**：3 分钟讲清「测试做什么」；能读懂简单 bug 单。

**本地**：`01-测试流程.md` · `03-测试八大要素.md`  
**网络**：

- [MoT 入门课（开发与测试导论）](https://www.ministryoftesting.com/courses/essentials-introduction-to-software-development-and-testing) — 最接近「学习区」入门课  
- [roadmap.sh · QA](https://roadmap.sh/qa) — 一张图看测试学习路径  
- [ISTQB Glossary（术语表）](https://glossary.istqb.org/) — 查标准定义（类似 MDN 查概念）  
- [Ministry of Testing](https://www.ministryoftesting.com/) — 社区与更多课程

## L1｜手工测试基础（先会测）

**目标**：对着页面/App 能按清单测完并记结果。

| 序号 | 学什么 | 学到什么程度 |
|------|--------|--------------|
| 1.1 | 环境、账号、版本、包体 | 确认测的是哪一版 |
| 1.2 | 冒烟 vs 功能 vs 场景 | 先冒烟再细测 |
| 1.3 | 需求 / 原型 / 验收标准 | 标出可测点与疑问 |
| 1.4 | 探索式测试章法 | 主路径→分支→异常→权限 |
| 1.5 | 提缺陷规范 | 环境、步骤、数据、截图、预期实际 |
| 1.6 | 提测说明 / 变更范围 | 会读、会追问 |

**学完标准**：独立测完一小模块，并提交合格缺陷（或写清无缺陷证据）。

**本地**：`01` · `04-功能测试要点` · `02-开发协作` · 课程 `01/04`  
**网络**：

- [Google Testing Blog](https://testing.googleblog.com/) — 大厂测试思路（选读）  
- [Front-End Checklist](https://github.com/thedaviddias/Front-End-Checklist) — 页面上线前检查灵感  
- [Production Ready Checklist](https://github.com/PrekshaShah2509/production-ready-checklist) — 发版前要盯什么

## L2｜用例设计与质量协作（会设计、会收口）

**目标**：会写用例、排优先级、出测试结论。

| 序号 | 学什么 | 学到什么程度 |
|------|--------|--------------|
| 2.1 | 用例八要素 | 字段写全 |
| 2.2 | 等价类、边界值 | 输入规则会设计 |
| 2.3 | 判定表、状态迁移、场景法 | 复杂规则会拆 |
| 2.4 | 优先级与冒烟清单 | 时间紧知道保什么 |
| 2.5 | 回归策略 | 改动面 + 高危 + 主链路 |
| 2.6 | 测试报告 / 轮次结论 | 覆盖、风险、是否建议发版 |
| 2.7 | 与产研协作 | 会问需求、会复现、会谈优先级 |

**学完标准**：能出用例表 + 一版本轮结论。

**本地**：`09-编写测试用例方法` · `10-测试用例八要素` · `03`  
**网络**：

- [ISTQB Foundation 大纲（Syllabus）](https://www.istqb.org/certifications/certified-tester-foundation-level) — 黑盒技法标准表述  
- [DevelopSense · Heuristic Test Strategy](https://www.developsense.com/blog/) — 启发式 / 探索式（选读 James Bach 一派）  
- [Preflight Playbook](https://github.com/penguinboi/preflight-checks/blob/main/production-readiness-playbook.md) — 发版审计提纲

## L3｜技术底子：Linux · 数据库 · 接口

**目标**：界面 + 接口 + 库表 三方验数。

| 序号 | 学什么 | 学到什么程度 |
|------|--------|--------------|
| 3.1 | Linux 常用操作 | 日志、进程、基础命令 |
| 3.2 | SQL | 查改、关联、按单号对账 |
| 3.3 | HTTP | 方法、状态码、Header、JSON |
| 3.4 | 抓包 | DevTools / Charles 等 |
| 3.5 | 接口测试 | Postman 调通 + 断言 + 串联 |
| 3.6 | 弱网 / 幂等入门 | 知道失败重试坑 |

**学完标准**：一次「下单成功」能同时核对界面、接口、库表。

**本地**：课程 `02` · `03` · `05`  
**网络**：

- [MDN · HTTP](https://developer.mozilla.org/zh-CN/docs/Web/HTTP) — HTTP 权威入门  
- [MDN · 学习 HTTP](https://developer.mozilla.org/zh-CN/docs/Web/HTTP/Guides/Overview) — 概览  
- [SQLBolt](https://sqlbolt.com/) — 互动学 SQL  
- [Postman Learning Center](https://learning.postman.com/docs/getting-started/introduction/) — 接口测试官方教程  
- [Linux Journey](https://linuxjourney.com/) — Linux 循序渐进（英文友好）
