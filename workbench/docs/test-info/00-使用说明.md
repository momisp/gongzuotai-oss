# 测试信息库 · 使用说明

面向测试工程师的随手查阅区：流程、要点、系统课程、本机资料与外部清单。

## 怎么用

1. 左侧选分类（知识手册 / **后端知识** / **课程资料** / 工作台文档 / 本机资料 / 外部链接）
2. 「课程资料」「后端知识」可再按学习阶段筛选
3. 点条目：Markdown/文本在弹窗阅读；PDF 在浏览器新标签打开；XMind/Word/代码用系统打开；外链跳转
4. 「扫描本机」刷新本机资料；「重建课程索引 / 重建后端索引」刷新对应分类

## 资料从哪来

| 来源 | 说明 |
|------|------|
| 知识手册 | 测试流程与要点（可改） |
| **后端知识** | 桌面「后端学习用」+ 精编 0→1 路径，见 `workbench/docs/backend-info/` |
| **前端知识** | 精编 0→1 路径 + 网络文档，见 `workbench/docs/frontend-info/`（可配 `frontend_root`） |
| 课程资料 | 本地 2022 软测课件索引 |
| 工作台文档 | `workbench/docs` 其它笔记 |
| 本机资料 | 扫描本机 PDF/MD 等 |
| **外部链接** | 网络公开资料（ISTQB、FastAPI、MDN、OWASP…） |

**从零学测试**：`test-info/11-测试知识学习目录.md`  
**从零学后端**：后端知识 → `01-后端知识学习目录.md`  
**从零学前端**：前端知识 → `01-前端知识学习目录.md`
