# 2022 软测课程体系索引

把百度网盘里的「14-2022年软测项目资料」整理成可按阶段查阅的课程库，挂在测试信息 → **课程资料**。

## 怎么用

1. 左侧点「课程资料」
2. 上方按学习阶段筛选（00 总览 → 08 项目文档）
3. 点条目：`.md` 弹窗阅读；`.pdf` 浏览器打开；`.xmind` / `.docx` 用系统默认程序打开
4. 课件目录有增删时，点「重建课程索引」（不拷贝文件，只刷新索引）

## 学习路径（建议顺序）

| 阶段 | 内容 | 典型资料 |
|------|------|----------|
| 00 总览导读 | 课程大纲、上课要求 | `2022年软测核心项目课程.pdf` |
| 01 手工测试基础 | 用例、缺陷、测试流程笔记 | 第 N 天笔记、手工项目课 |
| 02 Linux 与数据库 | 环境与 SQL | Linux / MySQL 讲义 |
| 03 Python 基础 | 脚本与断言入门 | Python PDF / 笔记 |
| 04 Web/App 手工项目 | TPshop、Ego 等项目测点 | Web/App 手工、业务场景测试点 |
| 05 接口与支付 | 抓包、接口、支付/金融案例 | Charles、黑马理财、接口笔记 |
| 06 自动化与报告 | 自动化与 Allure | SoloPi、Allure |
| 07 工具与部署 | 安装与部署说明 | 安装说明、项目部署 |
| 08 项目文档与案例 | 需求、说明书、练习与报告 | dayNN、需求文档 |

## 技术说明

- 索引文件：`data/test_info_course_index.json`（路径指向本机课件，**不入库拷贝**）
- 生成脚本：`workbench/build_course_index.py`
- 配置项：`data/test_info_config.json` → `course_root`
- 默认根目录：`F:\BaiduNetdiskDownload\14-2022年软测项目资料`
- 已排除：预习稿、作业答案、课堂代码树、截图与缓存，只留可查阅文档

## 与知识手册的关系

| 分类 | 用途 |
|------|------|
| 知识手册 | 工作台内置的流程/要点速查（短、实用） |
| 课程资料 | 系统化学习课件（长、按阶段） |
| 本机资料 | 其它扫描到的 PDF/MD（与课程去重） |

**按什么顺序学**：见知识手册 `11-测试知识学习目录.md`（L0→L5）；本文 00～08 是课件阶段，可嵌进该目录的 L1～L4。
