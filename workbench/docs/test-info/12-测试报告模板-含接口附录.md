# 测试报告模板（含接口附录）

> 自蜂巢 1.4.6 起约定：阶段报告（冒烟 / 功能 / 发版）均带 **附录 A · 相关接口清单**，并落一份 JSON 供后续接口自动化。  
> 参考实例：`F:\OA-test\项目安装包\oa蜂巢1.4.6（联运管理）\测试过程产出\冒烟测试报告-蜂巢1.4.6联运管理-20261012.md`

## 必备章节

1. 封面表（版本、阶段、时间、人员、结论）
2. 测试依据（原型 / 排期 / **Apifox 或接口文档链接** / 测点）
3. 排期与环境（前端地址、**接口 Base**、鉴权头）
4. 范围（内 / 外）
5. 执行清单（可回填 ⬜/✅/❌/⛔）
6. 结论与风险、后续动作
7. 产出物目录（`F:\OA-test\项目安装包\<项目>\测试过程产出\`）
8. **附录 A · 相关接口清单**（按模块分表；Method / Path / 名称 / 文档链接）
9. （可选）附录 B · 本约定说明

## 接口附录写法

| 项 | 要求 |
|---|---|
| 来源 | 本版 Apifox / OpenAPI 分享链接必须写进「测试依据」 |
| 粒度 | 只列本版相关模块，不必贴全站 System 接口 |
| 机读 | 同目录另存 `接口清单-<版本>-apifox.json`（含 path、method、doc、folder） |
| Method | 文档未写明可先推断并标 `*`，联调以 Apifox 为准 |
| 鉴权 | 写明 Header 名（如 `x-token`）与 Base URL |

## 冒烟与场景节奏（建议）

1. 先完成冒烟门禁清单并回填  
2. 冒烟通过后过一遍业务场景  
3. 再进入功能细项 / 回归（按排期）
