# 安全测试要点（测试工程师实用清单）

> 不是替代渗透团队，而是**日常提测就能拦住的基础安全问题**。权威清单见 OWASP Top 10。

## 1. 身份与会话

- [ ] 未登录不能访问需登录接口/页面
- [ ] 越权：A 用户不能读/改 B 的数据（改 ID 试）
- [ ] 退出后 token/session 失效
- [ ] 验证码/登录限流存在（防爆破）

## 2. 输入与注入

- [ ] 表单/搜索：脚本标签是否被执行或原样危险输出
- [ ] SQL 相关输入：引号、注释符是否异常
- [ ] 文件上传：类型、大小、路径穿越

## 3. 敏感信息

- [ ] 接口/前端是否泄露密钥、完整证件号、明文密码
- [ ] 日志、报错是否打出堆栈或内部路径
- [ ] HTTPS（生产）与明文传输风险

## 4. 业务逻辑安全

- [ ] 金额/次数/库存是否可被客户端篡改
- [ ] 优惠券、积分、提现等是否可重放
- [ ] 支付回调是否验签、是否幂等（参见工作台支付相关文档）

## 5. 配置与依赖

- [ ] 测试后门、调试开关未带到生产包
- [ ] 默认口令、弱口令
- [ ] 已知高危组件（有能力时用依赖扫描）

## 报告写法

写清：**复现步骤、影响范围、是否可未授权利用、建议修复**。  
安全类问题默认高优先级，除非能证明仅本地/仅测试环境。
