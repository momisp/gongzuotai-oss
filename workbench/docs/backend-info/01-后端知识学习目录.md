# 后端知识学习目录（普通人 0→1）

把桌面项目 **`后端学习用`**（FastAPI 实战 + 运维清单）整理成可执行路径。  
资料 = **本地项目** + **本手册** + **网络文档**。

## 你在学什么（一句话）

```
会写接口（FastAPI）→ 会存数据（MySQL）→ 会登录鉴权（JWT）
  → 会部署到「像服务器」的环境 → 会 Nginx / 守护 / 备份 / Docker
```

练手项目技能树（来自 `main.py`）：用户注册登录、文章/评论、商品订单、密码哈希、JWT、SQLAlchemy。

| 层级 | 定位 | 体感时间 | 学完能干什么 |
|------|------|----------|--------------|

## L0｜认知：后端是干什么的

| 学什么 | 学到什么程度 |
|--------|--------------|
| 前端 vs 后端 | 浏览器展示 vs 服务器算数/存数 |
| 请求一趟路 | URL → 服务器 → 数据库 → JSON 返回 |
| 常见组件 | Web 框架、数据库、反向代理、进程守护 |
| 和测试的关系 | 接口测的就是你写的这些 API |

**学完标准**：能画出「浏览器 → Nginx → FastAPI → MySQL」四格图。

**本地**：本说明 · 岗位对比文（了解协作）  
**网络**：

- [MDN · HTTP](https://developer.mozilla.org/zh-CN/docs/Web/HTTP)
- [MDN · 什么是 API](https://developer.mozilla.org/zh-CN/docs/Learn/JavaScript/Client-side_web_APIs/Introduction)

## 推荐学习顺序（一条路）

```
L0 认知
 → L1 Python + HTTP + SQL 入门
 → L2 跑通桌面「后端学习用」FastAPI 项目
 → L3 按《运维学习清单》阶段 0～2 部署到远程笔记本
 → L4 清单阶段 3～5（Nginx / 常驻 / 备份）
 → L5 清单阶段 6～10（Docker / 监控 / 安全 / 排障）
```

**时间紧的最小路径**：L0 → L2（本机 `/docs` 跑通）→ 清单阶段 2（能远程访问）→ 阶段 3+5（Nginx + 备份）。
