# 部署与运维上路（对照清单）

本地主文档：`后端学习用\运维学习\运维学习清单-远程版.md`。

## 阶段地图（来自你的清单）

| 阶段 | 主题 | 核心收获 |
|------|------|----------|
| 0 | 远程管理 | 连得上机器再谈部署 |
| 1 | WSL2 Linux | Win10 里练 Linux 基本功 |
| 2 | 部署 FastAPI | 项目在远程跑、外机可访问 |
| 3 | Nginx | 反向代理、统一入口、看日志 |
| 4 | 进程常驻 | supervisor，关机恢复 |
| 5 | 备份恢复 | 数据盘 + 定时备份 + **恢复演练** |
| 6 | Docker | 容器化 |
| 7 | 监控告警 | 知道挂了 |
| 8 | 安全 | 端口、权限、口令 |
| 9 | 自动化脚本 | 减少重复劳动 |
| 10 | 排障 | 日志→进程→网络→配置 |

## 两条部署支线

| 支线 | 文档 | 适合 |
|------|------|------|
| A WSL2 + 命令行 | 《运维学习清单》正文 + 附录 A/B | 更接近真实 Linux 运维 |
| B 宝塔 Windows | 《宝塔Windows版-FastAPI部署指南》 | 面板操作，贴近部分公司环境 |

可先 A 后 B，或只精做一条；**不要两条同时搅在同一端口上**。

## 最小闭环（先完成再进阶）

1. 阶段 0～2：服务可远程访问  
2. 阶段 3：Nginx 反代  
3. 阶段 5：备份且恢复成功一次  

然后再 Docker / 监控 / 安全。
