# 后端知识 · 使用说明

面向「想学后端 / 能部署能运维」的查阅区。资料来自：

1. **本目录精编手册**（从 0 到 1 的学习路径）
2. **本地项目** `桌面\后端学习用`（FastAPI 实战 + 运维清单原文）
3. **网络公开文档**（见各层「网络推荐」与测试信息 → 外部链接）

## 怎么用

1. 测试信息 → 左侧点 **后端知识**
2. 上方按阶段筛选（00 总览 → 07 本地原文）
3. 建议先打开 `01-后端知识学习目录.md`，按 L0→L5 顺序学
4. 本地项目有更新时：点「重建后端索引」
