## 新建改包页测试点

### 权限与初始化

- 未登录访问本页时被重定向到「登录」页
- 已登录但不具备「改包系统」新增权限时提示「您没有访问该页面的权限」并跳转「母包列表」页；与说明文档写「回任务列表」不一致时单独立项跟进产品定稿
- 具备权限时左侧「新建改包」菜单高亮；含系统权限用户可见「系统管理」分组

### 界面与原型一致

- 主卡片含「基础信息」Tab（当前仅此一项）、两列表单栅格与大区「签名文件」「埋点选项」跨列排布、「取消」与「提交改包任务」底部右对齐；字段标签顺序与占位符文案与 Html 一致

### 表单字段与上传校验

### 上传游戏母包

- 未上传时点「提交改包任务」出现「请上传游戏母包」弱提示且不弹出确认提交窗
- 仅允许选择 apk 或 ipa 后缀文件；选中后展示区显示文件名与体积，上传区收起
- 解析完成后「系统类型」按扩展名填入 Android 或 iOS；弹出「游戏母包解析成功」类成功提示，并回填游戏名称、包名、版本号、targetSdkVersion 等的模拟字段，可与后续真实接口映射对账
- 点击移除恢复上传入口并清空系统自动回填的游戏信息字段


### icon

- 未上传时点提交出现「请上传icon图片」
- 选择图片后出现缩略预览、文件名、大小；移除后恢复上传入口


### 系统类型

- 输入框为禁用灰底，无法在不上传母包时手改；清空母包后该字段清空
- 提交前若为空则拦截「系统类型不能为空」


### 游戏名称、包名、版本号

- 任一为空分别有「游戏名称不能为空」「请输入包名」「请输入版本号」提示；允许在自动解析后继续手改并成功提交


### 推广属性与渠道辅助

- 为空时提交提示「请输入推广属性」；支持手输或通过右侧图标按钮打开「选择渠道」弹窗回填

### targetSdkVersion

- 为空时提示「请输入targetSdkVersion」；解析成功时可被预填，仍允许手工修改


### 签名文件、密钥别名、密钥密码

- 未上传签名时出现「请上传签名文件」
- 上传 `.jks` 或 `.keystore` 后展示文件信息并在下方显现「密钥别名」与「密钥密码」两行
- 「密钥别名」为只读触发下拉；模拟数据含多别名时须手选，`aliases.length === 1` 时自动带入唯一别名
- 别名未选时点提交提示「请选择密钥别名」；密码为空时提示「请输入密钥密码」
- 移除签名文件后隐藏别名与密码区并清空其值


### 埋点选项

- 「抖音 APPID」「快手 APPID」「快手 APPname」三框均可为空不拦截提交；《新建改包原型逻辑说明》中「埋点开关注入」若以独立版 Html 暂无开关控件，单列一条「当前页仅三文本框，不按有开关验收」便于产品增补后追测


### 取消与提交前置

- 点「取消」进入「改包任务列表」页且无提交确认框
- 全部必填通过后点「提交改包任务」先弹出确认窗而非直接后台提交


### 确认提交弹窗

- 标题「确认提交」；图示与主文案「确定要提交改包任务吗？」、补充说明「提交后将开始排队处理，请确认信息无误」
- 「取消」关窗不发最终提交语义；「确认提交」后出现「改包任务提交成功，正在排队处理...」，约 1.5 秒后自动跳转「改包任务列表」页


### 页面脚本稳定性

- 打开本页控制台无持续性脚本错误：若现存代码引用页面中不存在的下拉节点导致初始化异常，应按阻塞级缺陷登录并阻塞主流程验收


## 选择渠道弹窗测试点

### 界面与入口

- 从「推广属性」行右侧方块按钮打开；标题「选择渠道」；首行单行搜索占位「搜索平台或渠道账号...」与「搜索」按钮；中段「已选 N 个」计数；表头「全选勾选格、所属平台、渠道账号」；底部分页与「取消」「确认」与原型一致

### 搜索

- 输入关键词点「搜索」或键入关键字后渲染：仅展示平台名或账号名包含关键字的模拟行；无任何命中时中区展示「没有找到匹配的渠道」


### 列表、分页与勾选

- 点击行或行首复选框能切换该渠道是否进入已选集合，已选行有高亮背景
- 默认每页 5 条；底栏展示「共 N 条」与当前过滤结果一致；在第一页「上一页」禁用，末页「下一页」禁用，中间页码可点跳转且高亮当前页
- 表头勾选为全选当前过滤结果集合；部分选中行时表头为半选 indeterminate


### 已选计数

- 「已选 N 个」与当前勾选缓存条数实时一致


### 确认与关闭

### 需求便签「暂定单选 1 个」与实现对账

- 产品便签若定稿「仅能选择 1 个渠道」：连续勾选两行时应只保留最后一次或禁止第二项并提示，回填「推广属性」仅单行渠道语义，与当前脚本用分号拼接多行「平台:账号」行为对照，不一致走需求变更或缺陷


### 当前 Html 回填规则

- 点「确认」将选中集合按「平台:账号」用英文分号连接写入推广属性输入框并关窗；点「取消」或「×」关窗不写回
