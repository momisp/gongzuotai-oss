## 岗位管理页测试点

### 权限与初始化

- 未登录访问本页时被重定向到「登录」页
- 已登录但不具备「系统管理」模块查看权限时提示「您没有访问该页面的权限」并跳转至「母包列表」页；与《岗位管理原型逻辑说明》中「跳转任务列表」表述不一致时在缺陷或需求池中单独立项确认目标页
- 具备权限进入后顶部标题为「岗位管理」，左侧菜单「岗位管理」为选中高亮

### 界面与原型一致

- 「岗位列表」卡片含右上角主按钮「新增岗位」；表头列为「岗位名称、岗位描述、包含权限、创建时间、操作」；空列表时展示「暂无岗位数据」占位，与脚本一致

### 列表（表格）

- 「岗位名称」列主文案加粗或强调样式与示例一致；系统内置「超级管理员」或 id 为 `role_admin` 的记录带「系统默认」绿色标签且操作列不出现「删除」
- 「岗位描述」无内容时展示「-」
- 「包含权限」列以标签形式罗列已授权的一级模块中文名（游戏管理、改包系统、系统管理等），与 `Permission.PAGES` 映射一致可对账
- 「创建时间」与存储字段一致
- 「操作」列对每个岗位展示「编辑」；非系统默认岗位另展示红色「删除」

### 搜索（筛选）

- 本页无独立筛选栏，本节不写虚假筛选项


### 分页组件

- 本页列表未分页则不展开分页范式


### 顶部用户区与个人相关弹窗

- 与个人中心、「修改密码」「退出登录」的交互与同系统其他后台页一致，弱提示约 3 秒消失


## 新增岗位弹窗与编辑岗位弹窗测试点

### 界面与入口

- 点击「新增岗位」打开弹窗，标题为「新增岗位」；表单含「岗位名称」必填、「岗位描述」选填、「岗位权限」必填树，底部「取消」「保存」与右上角「×」关闭与原型一致
- 打开新增时岗位名称与描述为空，权限树全部未勾选，既往校验红框与错误行文案被清除
- 点击某行「编辑」打开弹窗标题为「编辑岗位」，名称、描述、勾选项与该岗位 Storage 记录一致，`role_admin` 可编辑但以业务是否允许改动系统岗为准

### 关闭与取消

- 点「×」、「取消」或遮罩空白处关闭弹窗后再次打开新增，不应残留上一份未提交的填写内容


### 岗位名称校验

- 未填时点「保存」，「岗位名称」行下出现「请填写岗位名称」，弹窗不关
- 长度不在 1～20 汉字或字符策略内时出现「岗位名称长度为1-20个字符」文案，与 Validator 一致
- 输入含脚本所列特殊符号集合时出现「岗位名称不能包含特殊符号」
- 与已有岗位同名时出现「岗位名称已存在，请重新输入」
- 编辑态下允许与本人原名相同但不得与其他岗位重名


### 岗位描述

- 可不填仍可保存成功；超长或换行若以产品另有限制时再补边界条


### 岗位权限树结构

- 三组一级节点：「游戏管理」「改包系统」「系统管理」，各组下四级子权限「查看、新增、编辑、删除」，右侧附带说明短语与 Html 一致
- 每组标题行有折叠箭头，点击能在展开与收起子行间切换


### 全选与各选

- 点击某组「全选」文字链：应在「全勾选」与「全不勾」之间切换一组内四个子项与父勾选视觉状态同步
- 点击一级父勾选：勾选时应自动勾上该组「查看」，并批量联动子项与半选（indeterminate）态符合 Html 写法；取消父勾选应清空组内子项


### 需求说明第 5.5 条联动与实现核对

- 《岗位管理原型逻辑说明》：勾选任一「新增」「编辑」「删除」子项时应默认连带勾选同组「查看」；若在页面上可先勾「新增」而「查看」仍为未勾，应按需求提交缺陷或由产品确认为接受差异


### 保存成功路径

- 名称合法且至少勾选一条具体权限映射到 `permissions.pages` 非空时点「保存」：新增提示「岗位创建成功」、编辑提示「岗位更新成功」，弹窗关闭，列表即时刷新可对账 LocalStorage


## 删除岗位弹窗测试点

### 界面与入口

- 非系统默认岗位点「删除」出现标题「删除岗位」弹窗，中部三角警示图标，主文「确定要删除该岗位吗？」，副文根据是否已关联账号切换

### 删除前提示分支

- 岗位下仍绑定用户时副文为「该岗位已关联账号，不可删除，请先解除账号与该岗位的关联」；此时点「确认删除」应提示「该岗位已关联账号，不可删除，请先解除账号与该岗位的关联」类失败弱提示且列表数据不变
- 未绑定用户时副文为「删除后无法恢复，请谨慎操作」；点「确认删除」后提示「岗位删除成功」，弹窗关闭，该岗位从列表消失且存储中无此 id

### 取消与遮罩

- 点「取消」「×」或遮罩不删数据，列表不变
