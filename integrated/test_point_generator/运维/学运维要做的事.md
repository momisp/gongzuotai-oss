# 学运维可以做的事（简版）

- **基础**：熟悉 Linux 常用命令、文件权限、进程与服务（systemd 等）。
- **网络**：理解 IP、DNS、HTTP/HTTPS、防火墙与安全组概念。
- **容器与编排**：Docker 入门；有需要再学 Kubernetes 基础概念与常用操作。
- **自动化**：Shell/Python 写简单脚本；了解 CI/CD（如 Jenkins、GitLab CI、GitHub Actions 其一）。
- **监控与日志**：会看服务日志、资源占用；了解 Prometheus/Grafana 或云厂商监控大屏其一即可。
- **云与基础设施**：选一家公有云，实践虚拟机、对象存储、负载均衡、数据库托管等最常用能力。
- **安全与规范**：账号与密钥管理、最小权限、备份与回滚意识。
- **实践**：搭一个小站点或 API，从部署、发版、扩容到故障排查走通一遍。

按需深入，不必一次求全；以「能部署、能排错、能自动化」为阶段性目标即可。
