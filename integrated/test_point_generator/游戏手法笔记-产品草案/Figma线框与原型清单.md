# Figma 线框与原型清单

用于个人原型阶段：每个 Frame 对应一屏，原型连线表达「从哪点到哪」。

## 建议 Frame 命名

- `P1-封面首页-封面图+主按钮`
- `P2-游戏列表与切换`
- `P3-条目列表-筛选`
- `P4-条目详情-阅读`
- `P5-条目编辑-元数据`
- `P5b-条目编辑-步骤列表`（可与 P5 同屏上下滚动）

## 每屏必画元素（低保真即可）

| Frame | 必含元素 |
|-------|----------|
| P1 | **整页或主区域为封面图**（用户上传示例态 + 无图占位态各一 Frame 更佳）；**居中主按钮**（进入主流程）；可选角落「更换封面」/`file` 上传入口 |
| P2 | 游戏行列表、添加游戏、`当前` 标记、进入该游戏条目列表 |
| P3 | 筛选 chips（类型/标签）、条目行（标题、队伍、更新时间）、点击进入详情 |
| P4 | 大标题、类型与版本、正文区、步骤列表（或时间轴占位）、底部 `编辑` |
| P5 | 标题、类型、队伍名、`game_version` 输入、标签输入、`body` 多行、`steps` 可增删行、保存/取消 |

## 原型交互（Prototyping）建议连线

1. **P1 主按钮** → **P2**；P2 选中某游戏 → P3。（从封面进入后的流程与此前一致。）
2. P3「新建」→ P5；P5「保存」→ P4 或 P3。
3. P3 点击行 → P4；P4「编辑」→ P5。
4. 可选：P2/P3 等内「返回」若需回到封面，可连回 P1（或仅浏览器返回上一级，首版可二选一）。

## 交付给 AI / 开发时

- 导出关键帧 **PNG** 或 Figma **Dev Mode** 链接（若协作）。
- 附 `产品设计草案.md` 中的数据字段表（含 **P1 封面** 对应的 `AppPreferences`），避免仅凭截图猜结构。
