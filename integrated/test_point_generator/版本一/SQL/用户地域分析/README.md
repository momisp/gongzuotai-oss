# 用户地域分析 SQL

## 目录说明

| 文件 | 说明 |
|------|------|
| 01-全部用户地域分析.sql | 统计全部用户的地域分布 |
| 02-新用户地域分析.sql | 统计指定日期范围内新注册用户的地域分布 |
| 03-活跃用户地域分析.sql | 统计指定日期范围内活跃用户的地域分布（按用户去重） |

## 数据说明

- **region 字段格式**：`省份 城市 区县`，如 `福建省 泉州市 鲤城区`
- **地域层级**：可按省、市、区三级分析
- **内部人员**：所有查询均排除 `isInternal = 1` 的用户

## 使用说明

1. 替换日期参数：将 `2026-03-20`、`2026-03-21` 改为实际查询日期
2. 表名前缀：按实际库名调整 `yyz_big_party`
