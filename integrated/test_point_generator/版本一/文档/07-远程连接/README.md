## 🚀 快速开始

### 推荐工具（2024最新）

1. **Windows 远程桌面（RDP）** - Windows 服务器
2. **SSH** - Linux 服务器（最常用）
3. **MobaXterm** - Windows 上最好的 SSH 工具
4. **VS Code Remote** - 代码编辑器远程连接

### 快速选择

- **Windows 服务器** → Windows 远程桌面（RDP）
- **Linux 服务器** → SSH（推荐 MobaXterm）
- **需要图形界面** → 远程桌面
- **只需要命令行** → SSH
