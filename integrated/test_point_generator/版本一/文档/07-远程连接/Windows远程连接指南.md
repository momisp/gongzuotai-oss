# Windows 远程连接指南

## 🎯 Windows 远程桌面（RDP）

**Windows 远程桌面**是 Windows 系统自带的远程连接工具，用于连接 Windows 服务器。

---

## 🚀 快速连接（3步）

### 步骤1：打开远程桌面

**方法1：使用运行命令**
```
Windows 键 + R
输入：mstsc
回车
```

**方法2：开始菜单**
```
开始菜单 → 搜索「远程桌面连接」
```

**方法3：命令提示符**
```cmd
mstsc
```

### 步骤2：输入连接信息

**填写：**
- **计算机名**：服务器 IP 地址（如：`192.168.1.100`）
- **用户名**：服务器用户名（如：`Administrator`）

**高级选项：**
- 点击「显示选项」
- 可以保存凭据
- 可以设置显示选项

### 步骤3：连接

1. 点击「连接」
2. 输入密码
3. 如果提示证书警告，点击「是」
4. 连接成功

## 🔧 详细配置

### 保存连接配置

1. **打开远程桌面**
   - 输入服务器地址
   - 点击「显示选项」

2. **配置选项**
   ```
   常规：
   - 计算机名：192.168.1.100
   - 用户名：Administrator
   - 勾选「允许我保存凭据」
   
   显示：
   - 分辨率：选择合适的分辨率
   - 颜色：最高质量
   
   本地资源：
   - 可以共享剪贴板
   - 可以共享驱动器
   ```

3. **保存配置**
   - 点击「常规」标签
   - 点击「另存为」
   - 保存为 `.rdp` 文件
   - 下次双击文件即可连接

## 💡 常用功能

### 1. 共享剪贴板

**配置：**
- 远程桌面 → 显示选项 → 本地资源
- 勾选「剪贴板」

**使用：**
- 在远程桌面中复制
- 在本地粘贴（或反之）

### 2. 共享驱动器

**配置：**
- 远程桌面 → 显示选项 → 本地资源
- 点击「详细信息」
- 勾选要共享的驱动器

**使用：**
- 在远程桌面中，打开「此电脑」
- 可以看到共享的本地驱动器

### 3. 全屏模式

**快捷键：**
- `Ctrl + Alt + Break`：切换全屏
- `Ctrl + Alt + Home`：显示连接栏

## 🔐 安全设置

### 服务器端配置（需要管理员权限）

1. **启用远程桌面**
   ```
   系统属性 → 远程 → 启用远程桌面
   ```

2. **配置防火墙**
   ```
   允许端口 3389（RDP 默认端口）
   ```

3. **设置用户权限**
   ```
   系统属性 → 远程 → 选择用户
   添加允许远程连接的用户
   ```

## ⚠️ 常见问题

### 问题1：无法连接

**检查：**
1. 服务器是否开启远程桌面
2. 防火墙是否允许端口 3389
3. 网络是否连通
4. 用户名密码是否正确

**测试：**
```cmd
# 测试网络
ping 192.168.1.100

# 测试端口
telnet 192.168.1.100 3389
```

### 问题2：连接慢

**优化：**
1. 降低显示质量
2. 关闭不必要的视觉效果
3. 检查网络带宽
