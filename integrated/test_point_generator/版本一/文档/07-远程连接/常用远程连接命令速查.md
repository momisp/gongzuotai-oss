# 远程连接命令速查表

## 🚀 快速参考

### SSH 连接（Linux）

```bash
# 基本连接
ssh username@hostname

# 指定端口
ssh -p 2222 username@hostname

# 使用密钥
ssh -i /path/to/key.pem username@hostname

# 断开连接
exit
```

### Windows 远程桌面

```cmd
# 打开远程桌面
mstsc

# 或指定服务器
mstsc /v:192.168.1.100
```

## 📋 常用命令

### 文件传输

**SCP（复制文件）**
```bash
# 上传文件
scp file.zip username@hostname:/path/to/dest/

# 下载文件
scp username@hostname:/path/to/file.zip ./

# 复制目录
scp -r directory username@hostname:/path/to/dest/
```

**SFTP（文件传输协议）**
```bash
# 连接 SFTP
sftp username@hostname

# SFTP 命令
put localfile remotefile    # 上传
get remotefile localfile     # 下载
ls                          # 列出文件
cd directory                # 切换目录
```

## 🔧 服务器操作

### 基本命令

```bash
# 查看当前目录
pwd

# 列出文件
ls
ls -l    # 详细
ls -la   # 包括隐藏文件

# 切换目录
cd /path/to/directory
cd ~     # 用户目录
cd ..    # 上一级

# 查看文件
cat filename
less filename
head filename
tail filename

# 编辑文件
vi filename
nano filename
```

### 系统信息

```bash
# 系统信息
uname -a

# 磁盘使用
df -h

# 内存使用
free -h

# 进程
ps aux
top
```

## 💡 实用技巧

### 保持连接不断开

```bash
# 使用 screen
screen -S session_name
# 执行命令
# Ctrl+A+D 断开（保持运行）
# screen -r session_name 重新连接

# 使用 tmux
tmux new -s session_name
# Ctrl+B+D 断开
# tmux attach -t session_name 重新连接
```

### 后台运行命令

```bash
# 后台运行
command &

# 后台运行并输出日志
nohup command > output.log 2>&1 &

# 查看后台任务
jobs

# 查看进程
ps aux | grep command
```

---

**记住：SSH 用 exit 断开，文件用 scp 传输！** 🚀
