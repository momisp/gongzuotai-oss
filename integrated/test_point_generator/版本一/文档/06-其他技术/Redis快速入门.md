# Redis 快速入门（5分钟理解）

## 🎯 核心概念（30秒）

```
Redis = 超快的内存数据库
用途 = 缓存数据，提高速度
特点 = 临时存储，可以过期
```

**类比：**
- 数据库 = 图书馆（永久保存，查找慢）
- Redis = 桌面笔记本（临时保存，查找超快）

---

## 💡 为什么需要 Redis？

### 没有 Redis

```
用户请求 → 查询数据库 → 返回结果
时间：100ms（慢）
```

### 有 Redis

```
用户请求 → 查 Redis（1ms，快）→ 返回结果
         → 没有 → 查数据库 → 存入 Redis → 返回
```

**效果：** 第二次查询快 100 倍！

---

## 🔑 三个核心概念

### 1. 键值对（Key-Value）

```
Key（键）      Value（值）
----------    ----------
user:1001     {"name":"张三"}
token:abc     "eyJhbGc..."
count         100
```

### 2. 内存存储

- 数据存在内存中
- 读写速度非常快（微秒级）
- 但内存有限，成本高

### 3. 过期时间

- 可以设置数据过期时间
- 过期后自动删除
- 适合临时数据（token、验证码）

---

## 📊 Redis vs 数据库

| 特性 | Redis | 数据库 |
|------|-------|--------|
| **速度** | 非常快 | 相对慢 |
| **存储** | 内存 | 磁盘 |
| **用途** | 缓存 | 永久存储 |
| **成本** | 高 | 低 |

---

## 🎯 实际应用

### 应用1：缓存用户信息

```
第一次：数据库查询 → 存入 Redis
后续：Redis 查询（快）
更新：更新数据库 → 删除 Redis
```

### 应用2：存储 Token

```
登录 → 生成 Token → 存入 Redis（设置过期时间）
后续请求 → 从 Redis 获取 Token
过期 → 重新登录
```

### 应用3：提高接口性能

```
热点数据 → 存入 Redis
接口查询 → 先查 Redis → 没有再查数据库
```

## 🧪 测试场景

```

```

```
1. 设置缓存过期时间

3. 验证是否重新查询数据库
```

## 📚 基本命令（了解即可）

```bash
# 设置值
SET key "value"

# 获取值
GET key

# 设置过期时间
SET key "value" EX 3600

# 删除
DEL key
```
