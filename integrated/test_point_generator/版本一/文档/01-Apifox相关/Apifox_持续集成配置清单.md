## ✅ 阶段2：Runner 部署

### Docker 容器部署

- [ ] Apifox Runner 镜像已拉取
- [ ] Runner 容器已启动
- [ ] 容器状态为 "Up"
- [ ] 端口 4524 已映射
- [ ] 数据目录已挂载

**验证命令：**
```bash
docker ps | findstr apifox-runner
docker logs apifox-runner
Test-NetConnection -ComputerName localhost -Port 4524
```

**快速部署：**
```bash
# 运行快速部署脚本
Apifox_Runner_快速部署.bat

# 或手动执行
docker pull apifox/apifox-runner:latest
docker run -d --name apifox-runner --restart unless-stopped -p 4524:4524 -v C:\apifox-runner-data:/data apifox/apifox-runner:latest
```

## ✅ 阶段3：Runner 配置

### 在 Apifox 中配置

- [ ] 已进入 Runner 设置页面
- [ ] 已添加 Runner
- [ ] Runner 名称已填写
- [ ] Runner 地址已填写（http://localhost:4524）
- [ ] Runner Token 已填写（如果需要）
- [ ] Runner 状态显示为「运行中」

**配置步骤：**
1. Apifox → 「自动化测试」→ 「Runner 设置」
2. 点击「添加 Runner」
3. 填写 Runner 信息
4. 保存并等待连接成功

**如果连接失败：**
- [ ] 检查 Docker 容器是否运行
- [ ] 检查端口是否可访问
- [ ] 检查防火墙设置
- [ ] 查看 Runner 日志
