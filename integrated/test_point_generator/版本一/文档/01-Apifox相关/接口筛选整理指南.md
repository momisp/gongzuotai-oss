# 接口筛选整理指南

## 🎯 目标

快速筛选和整理需要做自动化的接口，从接口文档和 Apifox 中提取接口信息。

---

## 📋 筛选原则

### 优先级分类

**P0 - 核心业务接口（必须自动化）**
- 登录/认证相关
- 核心业务流程（如：发布奇遇、抢奇遇）
- 支付相关
- 数据查询核心接口

**P1 - 重要业务接口（优先自动化）**
- 业务功能接口
- 数据修改接口
- 用户常用功能

**P2 - 一般接口（后续自动化）**
- 辅助功能接口
- 查询类接口
- 配置类接口

**P3 - 低优先级接口（可选）**
- 统计类接口
- 日志类接口
- 非核心功能

---

## 🚀 方法1：从 Apifox 中筛选（最推荐）

### 步骤1：导出 Apifox 接口列表

1. **打开 Apifox**
   - 进入你的项目
   - 选择「接口」标签页

2. **筛选接口**
   - 使用搜索框搜索关键词
   - 使用文件夹筛选
   - 使用标签筛选

3. **导出接口**
   - 方法1：全选接口 → 右键 → 「导出」→ 「OpenAPI 3.0」
   - 方法2：项目设置 → 「导入/导出」→ 「导出 OpenAPI」

### 步骤2：使用筛选工具整理

**使用提供的 Python 脚本：**
```bash
python 筛选接口.py
```

**脚本功能：**
- 解析 OpenAPI 文件
- 按模块分类
- 按优先级标记
- 生成 Excel 清单

---

## 🚀 方法2：从接口文档中提取

### 步骤1：整理接口文档

**常见格式：**
- Markdown 文档
- Word 文档
- Excel 表格
- Swagger/OpenAPI 文档

### 步骤2：提取接口信息

**需要提取的信息：**
- 接口名称
- 接口路径（URL）
- 请求方法（GET/POST/PUT/DELETE）
- 请求参数
- 响应参数
- 所属模块

### 步骤3：导入到 Apifox

1. **批量导入**
   - Apifox → 「导入」→ 「OpenAPI」
   - 选择导出的文件

2. **手动创建**
   - 在 Apifox 中手动创建接口
   - 复制接口文档内容

---

## 🚀 方法3：使用 Excel 整理（最简单）

### 步骤1：创建接口清单表格

**表格列：**
- 接口名称
- 接口路径
- 请求方法
- 所属模块
- 优先级（P0/P1/P2/P3）
- 是否自动化（是/否）
- 备注

### 步骤2：填写接口信息

**从接口文档中提取：**
- 逐个接口填写
- 标记优先级
- 标记是否需要自动化

### 步骤3：筛选需要自动化的接口

**筛选条件：**
- 优先级 = P0 或 P1
- 是否自动化 = 是

---

## 📊 接口分类建议

### 按业务模块分类

**用户模块：**
- 登录/注册
- 用户信息
- 我的奇遇
- 我的奖励

**商户模块：**
- 商户登录
- 发布奇遇
- 商户中心
- 核销记录

**商圈联盟模块：**
- 创建商圈
- 加入商圈
- 商圈管理

**其他模块：**
- 奇遇大厅
- 奖励相关
- 地址相关

### 按接口类型分类

**认证类：**
- 登录
- 注册
- Token 刷新

**查询类：**
- 列表查询
- 详情查询
- 搜索

**操作类：**
- 创建
- 更新
- 删除
- 提交
