# Apifox 接口分享方法指南

## 🎯 目标

将 Apifox 项目中的自动化接口分享给其他用户。

---

## 📋 分享方法（5种）

### 方法1：邀请团队成员（推荐，适合团队协作）

**适用场景：** 需要长期协作，多人共同维护接口

**步骤：**

1. **打开项目设置**
   - 打开 Apifox
   - 点击左侧「项目设置」

2. **邀请成员**
   - 找到「成员管理」或「邀请成员」
   - 点击「邀请成员」按钮

3. **选择邀请方式**
   - **邮箱邀请**：输入邮箱地址，发送邀请链接
   - **链接邀请**：生成邀请链接，发送给其他人
   - **二维码邀请**：生成二维码，扫码加入

4. **设置权限**
   - 选择成员角色：
     - **管理员**：所有权限
     - **开发者**：可以编辑接口
     - **只读**：只能查看

5. **发送邀请**
   - 被邀请人点击链接或扫码加入项目
   - 即可查看和协作接口

**优点：**
- ✅ 实时同步
- ✅ 多人协作
- ✅ 权限管理
- ✅ 长期有效

---

### 方法2：导出接口文档（推荐，适合文档分享）

**适用场景：** 需要分享接口文档给外部人员或存档

**步骤：**

1. **打开分享文档**
   - 点击左侧「分享文档」
   - 或进入「项目设置」→「分享文档」

2. **配置文档**
   - 选择要分享的接口
   - 设置文档标题和描述
   - 选择文档格式（HTML、Markdown、PDF）

3. **生成文档**
   - 点击「生成文档」
   - 等待生成完成

4. **分享文档**
   - **在线链接**：复制文档链接，发送给其他人
   - **导出文件**：下载 HTML/PDF 文件，发送给其他人
   - **二维码**：生成二维码，扫码查看

**优点：**
- ✅ 格式美观
- ✅ 可以离线查看
- ✅ 适合文档存档
- ✅ 不需要 Apifox 账号

---

### 方法3：导出接口文件（适合备份和迁移）

**适用场景：** 需要备份接口或迁移到其他项目

**步骤：**

1. **选择接口**
   - 在接口列表中，选择要导出的接口
   - 可以多选

2. **导出接口**
   - 右键点击接口 → 「导出」
   - 或点击「更多」→「导出」

3. **选择格式**
   - **OpenAPI**：标准格式，兼容性好
   - **Apifox**：Apifox 专用格式
   - **Postman**：Postman 格式
   - **HAR**：HTTP Archive 格式

4. **保存文件**
   - 选择保存位置
   - 保存文件

5. **分享文件**
   - 将文件发送给其他人
   - 其他人可以导入到自己的 Apifox 项目中

**优点：**
- ✅ 可以备份
- ✅ 可以迁移
- ✅ 格式标准
- ✅ 离线使用

---

### 方法4：复制接口（适合快速分享）

**适用场景：** 需要快速复制接口到其他项目

**步骤：**

1. **选择接口**
   - 在接口列表中，选择要分享的接口

2. **复制接口**
   - 右键点击接口 → 「复制」
   - 或使用快捷键 `Ctrl+C`

3. **切换到目标项目**
   - 打开要分享到的项目
   - 选择目标文件夹

4. **粘贴接口**
   - 右键点击文件夹 → 「粘贴」
   - 或使用快捷键 `Ctrl+V`

**优点：**
- ✅ 操作简单
- ✅ 快速便捷
- ✅ 保留接口配置

---

### 方法5：分享测试场景（适合自动化测试分享）

**适用场景：** 需要分享自动化测试场景

**步骤：**

1. **打开自动化测试**
   - 点击左侧「自动化测试」
   - 选择要分享的测试场景

2. **导出测试场景**
   - 右键点击测试场景 → 「导出」
   - 或点击「更多」→「导出」

3. **选择格式**
   - **Apifox 格式**：保留完整配置
   - **JSON 格式**：标准格式

4. **分享文件**
   - 保存文件
   - 发送给其他人
   - 其他人可以导入到自己的项目中

**优点：**
- ✅ 保留测试配置
- ✅ 可以复用
- ✅ 适合团队协作

## 📝 详细步骤（邀请团队成员）

### 步骤1：打开项目设置

1. 打开 Apifox
2. 点击左侧「项目设置」
3. 或点击右上角「设置」图标

### 步骤2：邀请成员

1. 找到「成员管理」或「团队」部分
2. 点击「邀请成员」按钮

### 步骤3：选择邀请方式

**方式1：邮箱邀请**
```
1. 输入邮箱地址
2. 选择角色（管理员/开发者/只读）
3. 点击「发送邀请」
4. 被邀请人收到邮件，点击链接加入
```

**方式2：链接邀请**
```
1. 点击「生成邀请链接」
2. 复制链接
3. 发送给其他人
4. 其他人点击链接加入项目
```

**方式3：二维码邀请**
```
1. 点击「生成二维码」
2. 其他人扫码加入
```

### 步骤4：设置权限

**角色说明：**
- **管理员**：所有权限（创建、编辑、删除、邀请成员）
- **开发者**：可以创建和编辑接口
- **只读**：只能查看，不能编辑

## 📝 详细步骤（导出接口文档）

### 步骤1：打开分享文档

1. 点击左侧「分享文档」
2. 或「项目设置」→「分享文档」

### 步骤2：配置文档

1. **选择接口**
   - 选择要分享的接口或文件夹
   - 可以多选

2. **设置文档信息**
   - 文档标题
   - 文档描述
   - 文档封面（可选）

3. **选择格式**
   - **在线文档**：生成链接
   - **HTML**：下载 HTML 文件
   - **PDF**：下载 PDF 文件
   - **Markdown**：下载 Markdown 文件

### 步骤3：生成和分享

1. **生成文档**
   - 点击「生成文档」
   - 等待生成完成

2. **分享方式**
   - **在线链接**：复制链接分享
   - **下载文件**：下载后发送
   - **二维码**：扫码查看

---

## 📝 详细步骤（导出接口文件）

### 步骤1：选择接口

1. 在接口列表中，选择要导出的接口
2. 可以多选多个接口

### 步骤2：导出接口

1. **方式1：右键菜单**
   - 右键点击接口 → 「导出」

2. **方式2：批量导出**
   - 选择多个接口
   - 点击「批量操作」→「导出」

### 步骤3：选择格式

**推荐格式：**
- **OpenAPI 3.0**：标准格式，兼容性好
- **Apifox**：保留完整配置
- **Postman Collection**：Postman 格式

### 步骤4：保存和分享

1. 选择保存位置
2. 保存文件
3. 将文件发送给其他人
4. 其他人可以导入到 Apifox 或其他工具

---

## 🔧 导入接口（接收方操作）

### 步骤1：打开导入

1. 打开 Apifox
2. 选择目标项目
3. 点击「导入」或「+」→「导入」

### 步骤2：选择文件

1. 选择接收到的接口文件
2. 选择格式（OpenAPI、Postman 等）

### 步骤3：配置导入

1. 选择导入位置（文件夹）
2. 选择导入选项
3. 点击「导入」

## ⚠️ 注意事项

### 1. 权限管理

- 根据需求设置合适的权限
- 只读权限适合查看者
- 开发者权限适合协作者

### 2. 数据安全

- 分享链接时注意安全
- 敏感接口不要公开分享
- 定期更新分享链接

### 3. 版本同步

- 团队成员修改后会自动同步
- 导出文档需要手动更新
- 建议定期更新文档
