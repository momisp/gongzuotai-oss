# 接口自动化快速开始指南

## 🎯 你的场景

- ✅ 已经搭建了自动化 demo（Apifox + Jenkins）
- ✅ 有接口文档
- ✅ 有 Apifox 里面的接口数据
- ❓ 需要筛选整理接口，确定哪些要做自动化

---

## 🚀 3步快速开始

### 步骤1：筛选接口（5分钟）

**方法1：使用筛选工具（推荐）**

1. **从 Apifox 导出接口**
   - Apifox → 项目设置 → 导入/导出 → 导出 OpenAPI

2. **运行筛选脚本**
   ```bash
   python 文档/05-工具脚本/筛选接口.py openapi.json
   ```

3. **查看 Excel 清单**
   - 打开生成的 `接口清单.xlsx`
   - 查看优先级分类（P0/P1/P2/P3）
   - 标记需要自动化的接口

**方法2：手动筛选**

1. **在 Apifox 中查看接口**
   - 按模块浏览接口
   - 标记重要接口

2. **创建 Excel 清单**
   - 列出所有接口
   - 标记优先级
   - 标记是否自动化

---

### 步骤2：整理接口（10分钟）

**按模块分类：**
- 用户模块（登录、注册、用户信息）
- 商户模块（发布奇遇、商户中心）
- 商圈联盟模块
- 其他模块

**按优先级筛选：**
- **P0**：核心业务接口（必须自动化）
- **P1**：重要业务接口（优先自动化）
- **P2**：一般接口（后续自动化）
- **P3**：低优先级（可选）

**筛选标准：**
- P0/P1 接口 → 必须自动化
- P2 接口 → 根据时间决定
- P3 接口 → 可选

---

### 步骤3：创建测试场景（15分钟）

**在 Apifox 中创建测试场景：**

1. **创建场景文件夹**
   - 按模块创建场景
   - 如：用户模块、商户模块

2. **添加接口到场景**
   - 选择需要自动化的接口
   - 添加到测试场景

3. **配置测试用例**
   - 正常流程
   - 异常流程
   - 边界值

4. **配置环境变量**
   - 测试环境地址
   - 公共参数（Token 等）

---

## 📋 推荐工作流程

### 第1天：筛选和整理

1. **导出接口**
   - 从 Apifox 导出 OpenAPI
   - 或从接口文档提取

2. **筛选接口**
   - 使用筛选工具生成清单
   - 或手动整理 Excel

3. **确定优先级**
   - 标记 P0/P1 接口
   - 确定自动化范围

### 第2天：创建测试场景

1. **创建场景结构**
   - 按模块创建场景文件夹
   - 按优先级创建场景

2. **添加接口**
   - 将接口添加到场景
   - 配置测试数据

3. **编写断言**
   - 响应状态码
   - 响应数据
   - 业务逻辑

### 第3天：运行和优化

1. **运行测试**
   - 在 Apifox 中运行场景
   - 检查测试结果

2. **修复问题**
   - 修复失败的用例
   - 优化测试数据

3. **配置 CI**
   - 配置 Jenkins Pipeline
   - 设置定时任务
