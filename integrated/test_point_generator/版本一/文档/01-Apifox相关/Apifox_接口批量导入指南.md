# Apifox 接口批量导入指南

## 🎯 目标

快速将接口文档中的接口批量导入到 Apifox，提高效率。

---

## 🚀 方法1：从 OpenAPI 文件导入（最推荐）

### 步骤1：准备 OpenAPI 文件

**支持的格式：**
- OpenAPI 3.0（JSON/YAML）
- Swagger 2.0（JSON/YAML）

**获取方式：**
1. **从接口文档导出**
   - 如果接口文档是 Swagger/OpenAPI 格式，直接使用
   - 如果是其他格式，需要转换为 OpenAPI

2. **从 Apifox 导出**
   - Apifox → 项目设置 → 导入/导出 → 导出 OpenAPI
   - 用于备份或对比

### 步骤2：导入到 Apifox

1. **打开 Apifox**
   - 进入你的项目

2. **导入接口**
   - 点击「导入」按钮（左上角）
   - 选择「OpenAPI」
   - 选择文件
   - 点击「导入」

3. **配置导入选项**
   ```
   ✅ 覆盖同名接口（可选）
   ✅ 自动创建文件夹（推荐）
   ✅ 导入环境变量（如果有）
   ```

4. **完成导入**
   - 等待导入完成
   - 检查导入的接口

---

## 🚀 方法2：从 Postman 导入

### 步骤1：导出 Postman Collection

1. **打开 Postman**
2. **导出 Collection**
   - 选择 Collection
   - 点击「...」→ 「Export」
   - 选择格式（Collection v2.1）

### 步骤2：导入到 Apifox

1. **Apifox → 导入**
2. **选择「Postman」**
3. **选择文件**
4. **导入**

---

## 🚀 方法3：从 Excel 导入（需要转换）

### 步骤1：整理 Excel 表格

**表格格式：**
- 接口名称
- 接口路径
- 请求方法
- 请求参数
- 响应参数

### 步骤2：转换为 OpenAPI

**使用工具：**
- 使用提供的 Python 脚本转换
- 或手动创建 OpenAPI 文件

### 步骤3：导入到 Apifox

按照方法1的步骤导入。

---

## 🔧 导入后处理

### 步骤1：检查接口

1. **检查接口路径**
   - 确认路径正确
   - 确认参数正确

2. **检查请求参数**
   - 确认参数类型
   - 确认必填项

3. **检查响应**
   - 确认响应结构
   - 确认状态码

### 步骤2：整理接口

1. **创建文件夹**
   - 按模块创建文件夹
   - 按功能创建文件夹

2. **移动接口**
   - 将接口移动到对应文件夹
   - 使用拖拽或右键菜单

3. **添加标签**
   - 为接口添加标签
   - 便于筛选和管理

### 步骤3：配置环境

1. **创建环境**
   - 测试环境
   - 预发布环境
   - 生产环境

2. **配置环境变量**
   - 基础 URL
   - 公共参数
   - Token 等

### 常见问题

**问题1：导入失败**
- 检查文件格式
- 检查文件编码（UTF-8）
- 检查文件大小

**问题2：接口缺失**
- 检查 OpenAPI 文件是否完整
- 检查导入选项设置

**问题3：参数错误**
- 手动检查并修正
- 重新导入或手动编辑
