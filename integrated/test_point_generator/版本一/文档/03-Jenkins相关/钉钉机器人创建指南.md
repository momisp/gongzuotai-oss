# 钉钉机器人创建指南

## 🎯 目标

创建一个钉钉机器人，用于接收 Jenkins 测试报告通知。

---

## 📋 创建步骤

### 步骤1：打开钉钉群

1. 打开钉钉
2. 进入需要接收通知的群聊

### 步骤2：添加机器人

1. **点击群设置**
   - 点击群聊右上角的 **「设置」** 图标

2. **选择智能群助手**
   - 在设置中找到 **「智能群助手」**
   - 点击 **「添加机器人」**

3. **选择自定义机器人**
   - 选择 **「自定义」** → **「添加」**

### 步骤3：配置机器人

1. **填写机器人信息**
   ```
   机器人名称：Jenkins测试报告（或自定义）
   添加到群：选择当前群
   ```

2. **安全设置**（重要！）
   
   **选项1：加签（推荐）**
   - 选择 **「加签」**
   - 记录生成的 **「加签密钥」**
   - 格式类似：`SECxxxxxxxxxxxxx`
   
   **选项2：IP地址**
   - 选择 **「IP地址」**
   - 添加 Jenkins 服务器 IP 地址
   - 格式：`192.168.1.100`（根据实际 IP）

3. **完成创建**
   - 点击 **「完成」**

### 步骤4：获取 Webhook URL

1. **复制 Webhook 地址**
   - 创建完成后，会显示 Webhook 地址
   - 格式类似：
     ```
     https://oapi.dingtalk.com/robot/send?access_token=xxxxxxxxxxxxx
     ```
   - **重要：** 复制并保存这个地址

2. **记录加签密钥**（如果设置了加签）
   - 保存加签密钥，后续需要使用

---

## 🔐 安全配置说明

### 加签方式（推荐）

**优点：**
- 安全性高
- 防止 URL 泄露后被滥用

**使用方法：**
- 需要在发送消息时计算签名
- 签名算法：`HMAC-SHA256`

### IP 地址方式

**优点：**
- 配置简单
- 直接使用 Webhook URL

**缺点：**
- 如果 IP 地址变化，需要重新配置
- 安全性相对较低

---

## 📝 Webhook URL 格式

### 基础格式

```
https://oapi.dingtalk.com/robot/send?access_token=xxxxx
```

### 加签格式

```
https://oapi.dingtalk.com/robot/send?access_token=xxxxx&timestamp=xxxxx&sign=xxxxx
```

**参数说明：**
- `access_token`：机器人访问令牌
- `timestamp`：时间戳（毫秒）
- `sign`：签名（如果设置了加签）

## ✅ 测试机器人

### 方法1：使用 curl 测试

```bash
curl 'https://oapi.dingtalk.com/robot/send?access_token=your_token' \
  -H 'Content-Type: application/json' \
  -d '{
    "msgtype": "text",
    "text": {
      "content": "测试消息"
    }
  }'
```

### 方法2：使用 PowerShell 测试

```powershell
$body = @{
    msgtype = 'text'
    text = @{
        content = '测试消息'
    }
} | ConvertTo-Json

Invoke-RestMethod -Uri 'https://oapi.dingtalk.com/robot/send?access_token=your_token' `
  -Method Post `
  -Body $body `
  -ContentType 'application/json'
```

### 方法3：使用在线工具

- 访问：https://open.dingtalk.com/document/robots/custom-robot-access
- 使用官方提供的测试工具

## ⚠️ 注意事项

1. **保护 Webhook URL**
   - 不要将 Webhook URL 提交到代码仓库
   - 使用 Jenkins 凭据管理存储

2. **加签密钥安全**
   - 加签密钥同样需要保密
   - 建议使用 Jenkins 凭据管理

3. **机器人权限**
   - 机器人只能发送消息
   - 不能接收消息或执行操作

4. **消息频率限制**
   - 每个机器人每分钟最多发送 20 条消息
   - 超过限制会被限流
