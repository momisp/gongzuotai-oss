# Jenkins 定时构建触发器配置指南

## 🎯 目标

设置 Jenkins 每天 10:30 自动触发构建。

---

## ⏰ 快速配置（3步）

### 步骤1：进入任务配置

1. 打开 Jenkins
2. 选择你的任务
3. 点击「配置」

### 步骤2：找到构建触发器

1. 向下滚动找到「构建触发器」部分
2. 勾选「Build periodically」（定期构建）

### 步骤3：设置 Cron 表达式

在「日程表」文本框中输入：

```
30 10 * * *
```

**说明：**
- `30` = 分钟（30分）
- `10` = 小时（10点）
- `*` = 每天
- `*` = 每月
- `*` = 每周

---

## 📋 Cron 表达式格式

### 基本格式

```
分 时 日 月 周
*  *  *  *  *
│  │  │  │  │
│  │  │  │  └─── 星期几（0-7，0和7都表示周日）
│  │  │  └────── 月份（1-12）
│  │  └───────── 日期（1-31）
│  └──────────── 小时（0-23）
└─────────────── 分钟（0-59）
```

### 常用示例

| 需求 | Cron 表达式 | 说明 |
|------|------------|------|
| 每天 10:30 | `30 10 * * *` | 每天上午 10:30 |
| 每天 10:30（24小时制） | `30 10 * * *` | 同上 |
| 每天 22:30 | `30 22 * * *` | 每天晚上 10:30 |
| 每天 10:00 | `0 10 * * *` | 每天上午 10:00 |
| 每天 10:30 和 14:30 | `30 10,14 * * *` | 每天两次 |
| 工作日 10:30 | `30 10 * * 1-5` | 周一到周五 |
| 每小时 | `0 * * * *` | 每小时整点 |
| 每 30 分钟 | `*/30 * * * *` | 每 30 分钟一次 |

## 📊 Cron 表达式详解

### 字段说明

| 位置 | 字段 | 取值范围 | 说明 |
|------|------|---------|------|
| 1 | 分钟 | 0-59 | 分钟 |
| 2 | 小时 | 0-23 | 小时（24小时制） |
| 3 | 日期 | 1-31 | 每月的日期 |
| 4 | 月份 | 1-12 | 月份 |
| 5 | 星期 | 0-7 | 星期几（0和7=周日） |

### 特殊字符

| 字符 | 说明 | 示例 |
|------|------|------|
| `*` | 匹配所有值 | `* * * * *` = 每分钟 |
| `,` | 指定多个值 | `30 10,14 * * *` = 10:30 和 14:30 |
| `-` | 指定范围 | `30 10-14 * * *` = 10:30 到 14:30 每小时 |
| `/` | 指定间隔 | `*/30 * * * *` = 每 30 分钟 |

## 💡 常用时间配置示例

### 每天固定时间

```
每天 10:30    →  30 10 * * *
每天 14:00    →  0 14 * * *
每天 22:30    →  30 22 * * *
每天 00:00    →  0 0 * * *
```

### 工作日

```
工作日 10:30  →  30 10 * * 1-5
工作日 09:00  →  0 9 * * 1-5
```

### 特定时间

```
每天 10:30 和 14:30  →  30 10,14 * * *
每天 10:00 到 18:00（每小时）→  0 10-18 * * *
每 30 分钟  →  */30 * * * *
每小时整点  →  0 * * * *
```

## 📝 Pipeline 配置方式

### 在 Jenkinsfile 中配置

```groovy
pipeline {
  agent any
  
  // 定时触发器
  triggers {
      cron('30 10 * * *')  // 每天 10:30
  }
  
  stages {
    stage('运行测试') {
      steps {
        echo '执行测试...'
      }
    }
  }
}
```

### 多个时间点

```groovy
triggers {
    // 每天 10:30 和 14:30
    cron('30 10,14 * * *')
}
```

## ⚠️ 注意事项

### 1. 时区问题

**Jenkins 使用服务器时区：**
- 确认 Jenkins 服务器的时区设置
- 10:30 是服务器时间的 10:30，不是本地时间

**查看时区：**
- Jenkins → 系统管理 → 系统信息
- 查看「user.timezone」

### 2. 时间格式

**24 小时制：**
- `10` = 上午 10 点
- `22` = 晚上 10 点

### 3. 分钟和小时

**注意顺序：**
- 第一个是分钟
- 第二个是小时
- `30 10` = 10:30（不是 30:10）
