## 功能测试

### 会长网页端

#### 预支额度

##### 页面整体

- 界面与原型一致
  - 界面与UI图一致
  - 页面自上而下分为：顶部三张汇总卡片区、中部 Tab 与筛选区、底部数据表格与表尾操作区(含「一键还款」、分页等)，布局无错位、遮挡
  - 页面能体现「预支额度」或同级导航文案(以产品最终标题为准)

##### 顶部三张汇总卡

- 当前可预支额度
  - 卡片能显示标题「当前可预支额度」(以产品最终文案为准)
  - 能展示主数值，示例为「150,000」，千分位/小数位以产品统一规则为准
  - 能展示附说明文案(如已用信用占总授信比例，示例为「已用…占总额…45%」类表述)，与后台计算结果或接口一致
  - 能展示「立即预支」可点击入口(文字链或按钮样式以UI为准)
  - 点击「立即预支」，能弹出说明弹窗：明确「预支操作目前仅支持在 App 内完成」或同类表述，与产品 PRD 一致(以产品最终文案为准)
  - 弹窗内能展示 iOS(如 App Store)与 Android(如应用市场)的下载/安装指引，有「关闭」与「复制链接」(或同义按钮)等操作
  - 点击「复制链接」能完成复制(以浏览器权限为准)；复制成功时能有提示(如黄条提示「复制成功，请不要关闭当前弹窗」等原句或产品定稿)
  - 在显示复制成功提示时，按产品要求不自动关闭主说明弹窗，用户可继续按指引下载或手动关闭
  - 可预支额度与黄框业务公式能一致或可追溯：可预支金额 = (待结算金额 + 余额) - 已预支金额(以产品正名为准)；边界场景(待结算与余额互转、新增待结、已发生预支)下数值变化能符合产品给出的示例(如 100+50→可预支 150；待结转余额后总额度不变；新增待结+100 后可预支+100；预支 100 后可预支减少 100 等，用例按接口实际字段验算)
  - 可预支存在上限(如 100,000)时，展示值能不超过上限规则；若与卡面大数冲突以产品/环境说明为准

- 最高预支总额度(或同义「授信上限」)
  - 能显示主数值(示例 150,000)与产品口径一致(总额度/授信上限)
  - 能显示警示类说明(如发生违规将取消预支功能等)，完整引用产品定稿文字并用于验收
  - 无「立即预支」误操作(以原型为准)或仅展示只读

- 已预支待还额度
  - 能显示主数值(示例 150,000)与未结清预支的统计口径一致
  - 能显示「当前 N 笔待还」类副文案(示例为 3 笔)，N 与列表中状态为待还/未还清条数或产品统计一致
  - 能展示「立即还款」入口；点击后触发的弹窗/流程与表格区「还款」「一键还款」进入的确认还款为同一套逻辑(以产品/原型便签为准)

- 三卡与窗口适配
  - 三卡并排(或产品布局)时间距、阴影、主色与UI图一致；小屏/缩放下列表不遮挡卡片区
  - 卡片区数据加载中、失败时有 Loading 或明确错误态，不先展示 0 再跳变(以产品为准)

##### Tab 与筛选区(预支记录 / 还款记录)

- Tab 行为
  - 能显示「预支记录」「还款记录」两个 Tab；默认高亮「预支记录」
  - 切换至「还款记录」时，表头/列/筛选项变为还款列表所需(以产品表结构为准)
  - 切回「预支记录」时，恢复预支表列，筛选回显/清空按产品规则

- 预支记录 Tab 下筛选(以原型为准)
  - 能选择「状态」筛选(如已还清、待还等，选项以产品为准)
  - 能输入「预支编号」进行查询，预支编号格式为「YZ+日期+时间+3 位序号」类(如 YZ202604221430001)，支持精确/模糊以产品为准
  - 能输入或选择「关联代充」进行过滤(以产品控件形态为准)
  - 能点击「搜索」将条件带入请求，表格与表尾汇总数刷新
  - 无「搜索」时默认列表行为(进入页自动查询、无筛选等)以产品为准

- 还款记录 Tab 下筛选(与便签/原型)
  - 切换至「还款记录」时，Tab 为**蓝色下划高亮**(或产品选中态)，「预支记录」为未选态(与UI图一致)
  - 能显示「类型」下拉里筛选项(与列表「类型」列「全额还款/部分还款」可对应或含「全部」等，以产品为准)
  - 能显示「预支编号」输入框(与预支单 YZ 号一致，支持按号精确/模糊以产品为准)
  - 能显示「关联预支」输入框(用于定位某笔**预支单**下产生的还款，占位与校验规则以产品为准；若与预支 Tab 的「关联代充」命名不同，分别验收)
  - 能显示蓝色「搜索」按钮，点击后仅刷新**还款记录**表体与分页
  - 切换回「预支记录」时，预支侧筛选(状态、代充)与还款侧(类型、关联预支)独立记忆或清空以产品说明为准(避免串条件)

##### 预支记录列表

- 表头与列(预支记录 Tab)
  - 表头能依次展示：预支编号、预支金额、预支时间、已还金额、待还金额、关联代充、状态、操作(以产品最终列名为准)
  - 行内预支时间格式能统一为「YYYY-MM-DD HH:MM:SS」(如 2024-04-15 20:00:00)
  - 状态列能展示「已还清」且为绿色样式与「待还」或「待还款」类橙色样式，与行数据一致
  - 待还金额>0 且未结清时，操作列能显示「还款」类入口；已还清时操作列不展示可误点击的「还款」或置灰(以产品为准)
  - 预支金额、已还金额、待还金额以数字与千分位/小数位规则正确展示(如 10000.00、0、5000.00)
  - 关联代充能显示具体代充单号/名称，可点击时跳转或复制以产品为准

- 表尾与「一键还款」
  - 能展示汇总区文案，示例为「当前待还总额: 210,000，共 3 笔待还」或同类，总额与笔数与当前筛选/统计口径一致(以产品：全量待还/仅当前列表待还 为准)
  - 「一键还款」按钮在「待还笔数≥2」或产品约定条件下可点；可点时点击能进入与单条「还款」一致的「确认还款」类弹窗或流程(与便签 10 说明一致)
  - 当仅有 1 笔待还或 0 笔时，「一键还款」的展示为隐藏、置灰或仍可用(以产品为准)且行为符合规则

- 单条「还款」操作规则
  - 对「待还」行点击「还款」，能进入与「一键还款」相同逻辑的「确认还款」前序步骤(以产品便签为准)
  - 支持部分还款时：在余额小于待还时，能按产品规则用当前余额还一部分，并生成/展示对应还款记录(列表或还款记录 Tab)
  - 在可用余额为 0 时点击需要扣余额的「还款/确认」操作，不能完成扣款，能提示(如「余额不足，无法还款」或产品定稿)
  - 多笔未还时，若业务规定「单条也按时间从最早先冲」等，在部分还场景能体现冲账后的已还/待还更新正确

- 默认排序
  - 预支记录表默认以「预支时间」自新到旧排列(与业务扣款「从早到晚」是两套逻辑，本项仅验收列表默认排序)
  - 列头排序(如有)以产品说明验收

- 分页
  - 能展示总条数、每页条数、页码、可选「跳至第 X 页」
  - 翻页后筛选条件与 Tab 不丢失(以产品为准)，页尾待还笔数/总额与当前筛选口径一致(若与全局待还不一致，产品应说明，并单独写用例)

##### 还款记录列表(「还款记录」Tab)

- 表头与列(以原型定稿)
  - 表头能依次展示：还款编号、关联预支、还款金额、还款时间、类型(以产品列顺序为准，若增加「操作/详情」以产品为准)
  - 还款编号：能展示为「HK+日期+时间戳+3 位流水」等生成规则(示例 **HK20260414122302123** 格式，具体分段与长度以产品/后端为准)
  - 关联预支：能展示与本次还款**冲抵**的预支单号，与「预支记录」中**同一笔**的预支编号可一一对应(如 **YZ20260414122302123** 与 YZ 规则)
  - 还款金额：能展示为带千分位或两位小数的数字(如 **1,000** 或 1,000.00，以产品统一格式为准)
  - 还款时间：能统一为 **YYYY-MM-DD HH:MM:SS** 格式(如 **2026-04-14 20:00:00**)，与系统记账时间一致(与接口/订单中心时间戳可对账)
  - 类型列：能展示 **「全额还款」** 且为**绿色**文字；能展示 **「部分还款」** 且为**橙色**文字(色值/字重以UI图为准)
  - 行数据与行与行之间不合并：每一条独立还款在列表中**独占一行**、不可把多次扣款并格展示(便签6)

- 记录独立性与分次还款(便签6)
  - **任一次**点「确认还款」产生**一次**有效扣款，在「还款记录」中必新增**且仅新增**一条、且还款编号**全局(或同会长维度)不重复**的主键行为(以产品数据约束为准)
  - 对**同一笔**预支单分**两次**还款(如先还部分、后再还剩余)，在「还款记录」中**必须**出现**两条**独立记录：两条的「关联预支」相同、「还款时间」与「还款金额」可不同、两条各自有独立「还款编号」
  - 一次「一键还款」冲多笔时，在便签/实现上**每笔冲抵**若各自生成一条(或每确认一次生成多行)，以产品/接口为验收基准：行数=该次应生成的记录条数(便签6「每次一笔独立」)

- 类型判定与便签7(以产品**最终**口径为断言，下列覆盖两种常见实现，矛盾时以产品定稿留痕)
  - 若产品采用便签字面条目：**本笔还款金额 < 所关联预支单「预支金额」** 时，类型为「部分还款」；**=** 时类型为「全额还款」→ 在造数中准备预支 10,000、第一次还 1,000、第二次还 9,000 等组合，**逐行**核对该列展示与色；若多笔后累计才等于预支原额、单笔仍<原额，按产品要求验收(避免歧义时产品补充说明)
  - 若产品将「类型」定义为**本笔是否结清该预支单剩余应还**「结清=全额(绿) / 未结清=部分(橙)」→ 最后结清那笔(金额恰等于剩余)为绿，其前各笔为橙(与上条不兼容时，二选一，测试只执行终稿)
  - 列表中的「类型」与「确认还款/还款成功」弹窗中「全部/部分**笔数**」是不同维度(弹窗是**笔**、表是**每条还款**)，不强行数值相等、仅对账不矛盾

- 支付方式为「仅余额支付」(便签7)
  - 当前表头**不展示**「支付方式」列时，在验收用例中仍要**可追溯**：通过接口/详情页/对账单/导出处能核对本次还款的支付方式**仅有**「余额支付」(若未来扩展其它方式再补列，以产品为准)
  - 在「我的收益-当前余额」等同一余额池扣款时，对「还款成功」中金额与**还款记录**中「还款金额」逐笔可核对(见整体场景)

- 筛选与联动的组合
  - 在「类型」选「部分还款」后搜索，能只列出类型为**橙色部分还款**行；选「全额还款」则只出**绿色全额**行
  - 在「预支编号」输入已知的预支单号(如 YZ20260414122302123)后点击「搜索」，能列出与该**预支编号**相关的还款行(可 0/1/多条，分次还款时多条)
  - 在「关联预支」输入相同或不同关键字(以产品定义)后，与「预支编号」是否去重、是否二选一以产品为准；至少验收能通过其中一种方式查全**同一笔预支**下的全部还款流水
  - 无结果时，表格区有空态或「无数据」提示(以产品为准)

- 默认排序与分页(与预支区一致，数字示例对齐原型)
  - 能展示**共 243 条**类总条数(示例)、每页**显示 10 条**、页码(如 1…50)与**前往 [ ] 页**跳页(输入非法页/超出时提示，以产品为准)
  - 翻页、改每页条数后，**筛选**条件保持(以产品为准)；默认按「还款时间」**新到旧**或产品指定排序(在「分次两条」时两条顺序可读)

- 与「预支记录」的联动验收
  - 在「预支记录」中某行待还>0 时完成一次还款，切到「还款记录」**立即**能检索到新行(或按刷新策略)，「关联预支」= 该 YZ 号
  - 「查看记录」从成功弹窗进入本 Tab 时，**最新记录**在首屏/第一页(或按时间排序)可见

- 与「预支记录」的互斥(表区)
  - 在「还款记录」表区**不展示**表尾「当前待还总额+一键还款」(该区块属预支/待还操作区，以原型：还款 Tab 仅表+分页); 若产品将汇总挪至 Tab 上统一位置，以终稿调整用例

##### 可预支业务限制(自购不预支)

- 在订单来源为自购(给自己买)或产品定义不可预支的订单，不能生成/展示可预支额度增加或预支单(以产品埋点/订单类型与接口联调)
  - 有尝试预支入口时(主要在 App)被拦截，网页仅展示时数据不产生违规预支行(以环境分工为准)

##### 确认还款弹窗(与列表/表尾/卡片进入同源)

- 弹窗能显示标题「确认还款」，右上角有「X」能关闭
- 能显示「本次还款总金额」大字金额，示例 210,000
  - 能显示副说明，如「共1笔待还将一次结清」或「共N笔待还将按序冲抵」等(与本次业务实际 N 与是否一次结清一致，部分还时文案随产品)
- 支付方式为「余额支付」单选(或同义)，能展示「剩余 ¥ 124,124」类当前可用余额(格式与主站余额一致，千分位以产品为准)
- 能展示说明文：如「还款将从您的可用余额中直接扣除」等(完整照抄产品定稿)
- 点击「取消」能关闭弹窗且不发起扣款，来源页数据不变(若未过有效期)
- 点击「确认还款」时，在点击瞬间能再次校验收款时余额(防并发/前后端双检)：
  - 若余额足：能扣款并进入成功态
  - 若不足：能按产品规则作「部分结清/仅结清能覆盖部分」等，不静默失败(与黄框/便签5一致)
- 每点击一次有效「确认」对应生成独立还款操作记录(与「还款成功」统计笔数、金额可对账)
- 支持批量部分还款的边界：跨多笔时冲抵顺序为预支时间从早到晚(与便签); 多笔中部分完整还清、部分只还一部分时，与成功弹窗中「全部还款笔数」「部分还款笔数」能对应(见下节)

##### 还款成功弹窗

- 弹窗能显示标题「还款成功」与关闭「X」
- 「全部还款」行：能显示本次操作中「完全结清」的笔数(如 12 笔); 当笔数为 0 时该行能**隐藏**不展示(以产品便签4为准)
- 「部分还款」行：能显示本次仅冲抵部分应还未结清的笔数(如 1 笔); 当笔数为 0 时该行能**隐藏**
- 「还款金额」能显示本次实际扣款合计(示例 ¥ 232,121)，与余额扣减、各笔已还/待还更新之和一致(可接接口验算)
- 「当前余额」能显示扣款后剩余余额(如 ¥ 12,123)，与 扣款前余额-还款金额 一致(在并发与手续费为 0 前提)
- 点击「查看记录」能关闭成功弹窗并**跳转**到「还款记录」列表(或同义页面)，并刷新出最新操作产生的记录(以产品为准)
- 点击「关闭」能仅关闭成功弹窗，**停留**在预支额度当前页(或原列表页)，列表/三卡/表尾待还数能已刷新(以产品数据刷新范围为准)

##### 异常、权限与限流(视产品)

- 会话过期、重复点击「确认还款」的幂等(防二扣)、接口超时/失败有明确提示且余额与单据统计不误减(以产品/研发约定为准)
- 无预支功能权限的账号进入页面有拦截或空态(以产品为准)
