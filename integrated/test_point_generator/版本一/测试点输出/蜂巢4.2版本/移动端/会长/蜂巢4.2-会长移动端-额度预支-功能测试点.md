## 二、分区域要点清单（与上图树对应，便于执行）

### 2.1 便签1：预支编号与字段/按钮

| 项 | 验证要点 |
|----|----------|
| YZ 编号 | 新单符合 **YZ+日期+时间戳+3 位**；不重复 |
| 待还/已还/金额 | 预支金额、已还(累计)、待还(该笔)展示正确；已还清时待还=0 |
| 单条「立即还款」 | 仅待还态出现；**余额 0 拦截**；每成功一次独立 HK 记录 |
| 一键还款 | **≥2 笔**待还可见/可点；**批量部分** 按**时间从旧到新** 冲；**0 笔/1 笔** 不展示一键或置灰(依产品) |

### 2.2 便签4 / 10：确认与成功弹窗

- 确认：展示本次总金额、笔数、余额、仅余额付；**点确认瞬间**再校余额(并发/多端)
- 成功：**全额/部分笔数 为 0 不展示**；**查看记录** → 还款记录；**关闭** → 留当前

### 2.3 便签5 + 条6：还款记录列表与筛选

- HK 规则、**全额/部分** 与**还款额 vs 预支金额**比较、仅余额
- 筛选六段时间、**自定义日历** 双次选区、**重置/确认/标签/N**、**无数据** 文案、**与** 逻辑

### 2.4 便签7/9

- **去预支** → 代充并默认 **额度预支**；顶栏**吸顶**与**简化头** 切换
