# 会长侧预支 / 分佣 — 手工验算素材

本目录文件依据业务说明（可预支逻辑、真实/预支余额定义、还款优先级等）整理，用于对照系统数据是否一致。

| 文件 | 说明 |
|------|------|
| `验算表格-列说明与示例.md` | 与图六同构的列定义、公式、示例行与空白练习行 |
| `calculator.html` | 本地验算器：双库展示 + 每步快照表，便于导出或截图核对 |

**计算器口径摘要（与页面内规则一致）：**

- **真实余额库** = 累计现金充值分佣 − 还款中已消耗的现金分佣部分（≥0）。
- **预支余额库** = 已入账的、由预支代充分佣构成的余额池（还款时优先扣减）。
- **预支产生的待结算分佣**：预支本金入账后，对应 `本金×分佣比例` 可先记在待结算，再与「实际提现余额」展示一致（图六：`实际显示 ≈ 计算用余额 + 预支待结算`）。
- **可预支额度** = max(0, 真实余额库 − 待还预支本金)，且受白名单上限（默认 10 万）约束。
- **分佣比例**：默认 73%，可在页面修改。

若线上还有「玩家待结算」「未结算入真实库」等独立字段，请在 `验算表格` 中手工补列，与后台导出字段逐项对齐。
