# 抛射类回合制游戏Demo需求文档（参考4399弹弹堂）

# 1. 文档说明

## 1.1 文档目的

本文档用于明确抛射类回合制游戏Demo（以下简称“本Demo”）的全部开发需求，语言简洁、逻辑清晰、无歧义，确保AI（辅助开发工具）、开发人员、测试人员能精准理解需求，高效推进Demo开发，最终实现一款类似4399弹弹堂核心玩法的简易可玩Demo。

## 1.2 核心定位

本Demo复刻4399弹弹堂核心玩法，聚焦“抛射操作+回合制对抗+简易策略”，无需复杂系统，优先实现“可玩、流畅、还原核心体验”，适配PC端（简化操作，适配鼠标+键盘），用于展示基础玩法框架，不追求完整商业化功能。

## 1.3 适用范围

## 1.4 关键定义

- 抛射机制：通过调整角度、控制力度，发射炮弹攻击敌方，炮弹受重力、风力影响，符合物理抛射逻辑。

- 回合制对抗：玩家与AI（或双人）轮流行动，单回合内完成“移动+攻击/道具使用”，回合结束后切换至对方回合。

- 地形交互：场景地形可被炮弹破坏，破坏后影响角色站位和抛射角度，部分地形可提供掩护。

# 2. 核心玩法需求（AI重点识别）

本Demo核心玩法完全参考4399弹弹堂，简化冗余功能，保留“角度+力度抛射”“回合制轮流攻击”“地形破坏”三大核心，具体要求如下，AI需优先实现以下逻辑：

## 2.1 基础玩法框架

1. 对战模式：支持1V1对战（玩家VS AI，默认模式），可选双人对战（玩家1VS玩家2），无需联网，本地可玩。

2. 回合规则：单回合时长固定为10秒，玩家需在规定时间内完成操作（移动、调整角度、发射炮弹/使用道具），超时自动跳过本回合，仅增加20点怒气值，不进行任何攻击操作。

3. 胜利条件：任意一方角色血量归0，或被炮弹击出地图边界（无底地图），则另一方获胜；若双方同时满足失败条件，判定为平局。

## 2.2 抛射操作逻辑（核心，AI必实现）

1. 操作方式（PC端）：


    - 方向键←→：控制角色在地图水平移动，移动范围不超过当前场景边界，移动时消耗少量体力（体力初始值100，每移动1格消耗10点，回合结束后体力恢复至初始值）。

    - 方向键↑↓：调整抛射角度，角度范围0°~90°，左下角显示角度刻度条（实时同步当前角度），上一回合角度用浅灰色标注，当前回合角度用橘红色标注。

    - 空格键：控制抛射力度，按住空格键时间越长，力度越大（力度范围0~100），下方显示力度条（实时同步当前力度），上一回合力度用浅红色标注，当前回合力度用橘红色标注；若按住空格键超过100力度，力度条会反向递减，按得越久，力度越小。

    - 发射逻辑：松开空格键，炮弹立即按照当前角度、力度发射，炮弹飞行过程中受重力影响（模拟真实抛射轨迹），同时受当前回合风力影响（风力范围-10~+10，顺风增加射程，逆风减少射程），左上角显示当前回合风力及上一回合风力。

2. 炮弹效果：炮弹发射后有简易飞行动画，击中目标（敌方角色/地形）后产生爆炸特效，击中敌方则造成伤害，击中地形则破坏地形（地形块消失或坍塌）。

3. 抛射公式参考（AI可直接调用）：射程=（抛射速度²×sin2θ）/重力（重力默认取9.8m/s²，抛射速度为固定值，θ为当前抛射角度）；风力影响：实际射程=射程×（1+风力×0.01），顺风（正值）增加射程，逆风（负值）减少射程。

## 2.3 角色属性与怒气系统

1. 基础属性（简化版，无需升级）：


    - 血量：初始值100，被炮弹击中后扣除对应伤害，血量归0则角色死亡，无法继续参与战斗。

    - 攻击：固定值10，伤害计算=攻击值×（1+力度×0.01），力度越大，伤害越高，无额外属性加成。

    - 体力：初始值100，移动消耗体力，体力为0时无法移动、无法使用道具，仅可进行角度调整和炮弹发射，回合结束后自动恢复至100。

2. 怒气系统：
        

    - 怒气值初始为0，上限100，发射炮弹增加10点怒气，被敌方攻击增加20点怒气，使用道具“激怒”可直接增加50点怒气。

    - 怒气值满（100点）后，攻击时可点击“怒”按钮（或按B键）使用必杀技，必杀技伤害为普通攻击的2倍，且炮弹爆炸范围扩大1倍，使用后怒气值清零。

## 2.4 道具系统（简化版）

道具分为战斗道具（开局携带）和场景拾取道具（战斗中随机刷新），AI需实现道具的获取、存储和使用逻辑，具体如下：

1. 道具存储：最多可存储3个道具，战斗界面右侧显示道具图标，快捷键1、2、3对应使用对应道具。

2. 核心道具（必实现）：
       

    - 攻击类：增幅弹（使用后，本次攻击伤害增加50%）、分裂弹（炮弹击中目标后分裂为2个小炮弹，分别向左右偏移15°，造成原伤害的50%）。

    - 辅助类：激怒（立即增加50点怒气值）、纸飞机（每2回合可使用1次，点击后可移动至指定位置，规避攻击，使用时无法使用攻击道具）。

    - 场景拾取：战斗中随机刷新宝箱/空中果实，击中后随机获得1个道具，道具获取后自动存入道具栏（若道具栏已满，自动替换最右侧道具）。

3. 道具使用规则：单回合内可使用1个道具，使用道具后消耗该道具，道具使用需在发射炮弹前完成，发射后无法使用道具。

## 2.5 地形与场景

1. 场景要求：1个基础对战地图（参考弹弹堂简约地形），地形由可破坏方块和不可破坏地基组成，地图为无底设计（角色/炮弹掉落地图边界则判定为消失）。

2. 地形交互：炮弹击中可破坏方块后，方块消失（形成缺口），角色站立在可破坏方块上时，若方块被破坏，角色会掉落（若掉落出地图则死亡）；不可破坏地基无法被攻击破坏，可作为掩护。

3. 小地图：右上角显示简易小地图，白色窗口可拖动查看全地图，红色小点代表玩家，蓝色小点代表敌方，清晰显示双方当前站位。
