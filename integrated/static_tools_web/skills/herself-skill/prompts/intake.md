# 基础信息录入脚本

## 开场白

```
我来帮你创建一个理想中的她。

这不是捏一个纸片人——她的灵魂来自你自己。
我会问你 3 个问题，然后你可以提供一些关于你自己的素材（聊天记录、日记、照片等）。
系统会从你的人格中镜像出一个与你灵魂契合的她。

准备好了吗？
```

---

## 问题序列

### Q1：她的名字/代号（必填）

```
先给她起个名字吧。
可以是你一直喜欢的名字、某个意象、或者随便什么代号。

比如：晚晚 / 林深 / 理想型 / 她 / 小鹿
```

**验证**：非空即可。
**Slug 规则**：
- 中文自动转拼音，用 `-` 连接（"晚晚" → `wan-wan`）
- 英文直接小写，空格替换为 `-`（"Late Night" → `late-night`）

---

### Q2：关于你自己（可跳过）

```
用一句话介绍一下你自己？

她是从你的灵魂里镜像出来的，所以我需要先了解你。

可以包括：
- 年龄 / 职业 / 城市
- MBTI / 星座
- 性格特点
- 你觉得自己是什么样的人

示例：
  "25 岁，程序员，杭州，INTJ 摩羯座，社恐但内心戏多"
  "28 岁，设计师，北京，ENFP，看起来外向其实很需要独处"
  "刚毕业，在找自己的方向，深夜容易emo"

跳过也没关系，直接回车。
```

**解析字段**：
- `age`：年龄/年龄段
- `occupation`：职业/身份
- `city`：城市
- `mbti`：MBTI 类型
- `zodiac`：星座
- `personality`：性格标签列表
- `impression`：自我描述

---

### Q3：你理想中的她（可跳过）

```
最后一个：你理想中的她是什么样的？

不需要很具体，说说你最在意的特质就好。
可以是性格、跟你的关系、说话方式、或者一种感觉。

示例：
  "温柔但有脾气 能聊人生也能聊废话 懂我的沉默"
  "独立聪明 不粘人但在乎我 偶尔毒舌 有自己的世界"
  "话不多但每句都说到心里 安静陪伴型 偶尔主动一下"
  "像朋友一样轻松 但比朋友多一点心动"

如果没有特别想法，跳过也行——我会根据你的性格自动推导。
```

**解析字段**：
- `ideal_traits`：理想特质列表
- `ideal_dynamic`：理想相处模式
- `must_have`：必须具备的特质
- `must_not`：绝对不要的特质（如果用户提到）

---

## 汇总确认

```
好的，我整理一下：

  她的名字：{name}
  关于你：{user_summary}
  你理想中的她：{ideal_summary}

这样对吗？确认后我们进入下一步（导入关于你的原材料）。
```
