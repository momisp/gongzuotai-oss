  Grafana 自建仪表盘（配合 PromDapter / HWiNFO）
  不依赖网上模板；指标名以你机器上实际出现的为准。
═══════════════════════════════════════════════════════════

【一】先拿到「能用的指标名」
────────────────────────────────────────────────────────────
1. 本机浏览器打开（HWiNFO + PromDapter 须已运行）：
   http://127.0.0.1:10445/metrics
2. 页面里搜前缀：常见为 hwi_ 或 wmi_（以你页面为准）。
3. 或打开 Prometheus：http://127.0.0.1:9090 → Graph
   在查询框输入：{__name__=~"hwi.*"}  或  {__name__=~"wmi.*"}
   看「Table」里有哪些时间序列名，记下你想看的几条（例如 CPU 温度、GPU 温度、风扇转速等）。


【二】在 Grafana 里用「探索」试查询
────────────────────────────────────────────────────────────
1. 打开 Grafana：http://127.0.0.1:3000
2. 左侧点「探索」（Explore）。
3. 右上角数据源选 **Prometheus**。
4. 在查询框里粘贴你从 Prometheus 或 /metrics 里复制的一整条指标名，例如：
     hwi_xxx_yyy
   若只有一条，先点「Run query」，下方应出现曲线或表格。
5. 若提示「无数据」：
   - 去 Prometheus → Status → Targets，确认 **promdapter** 为 **UP**。
   - 确认 HWiNFO 已开共享内存且传感器窗口打开过。


【三】新建空白仪表盘并加第一个面板
────────────────────────────────────────────────────────────
1. 左侧「仪表板」→「新建」→「导入」旁边的「新建」或「新建仪表板」
   （不同版本文案：New → Dashboard → Add visualization）。
2. 数据源选 **Prometheus**。
3. 把「探索」里已经能出数据的查询，**原样复制**到「查询 A」里。
4. 右上角「应用」或「保存」。
5. 面板标题可双击改成「CPU 温度」等。
6. 右侧「面板选项」里可设：
   - 单位：摄氏度选 misc → °C，转速选 RPM，百分比选 percent（0-100）等。
   - 图例：Table / Bottom 等按个人习惯。


【四】同一页再添加多个指标
────────────────────────────────────────────────────────────
1. 仪表板右上角「编辑」（铅笔）→「添加」→「可视化」。
2. 每个面板用 **探索** 里分别试过的查询；**不要**复制网上不相关模板的查询。
3. 保存仪表板（起个名字，如「本机硬件」）。


【五】PromQL 小技巧（按需使用）
────────────────────────────────────────────────────────────
• 只显示某几个同名标签：在指标名后加大括号筛选，例如：
    hwi_xxx{sensor="CPU Package"}
  具体标签名以 Prometheus 里「Labels」为准。

• 若指标是「计数器」型（名字里常有 _total），可看每秒增量：
    rate(某指标名[1m])

• 时间范围：右上角选「最近 5 分钟」「最近 15 分钟」，比「过去 24 小时」更容易看到刚起来的数据。


【六】仍无数据时检查清单
────────────────────────────────────────────────────────────
□ HWiNFO 与 PromDapter 已运行，http://127.0.0.1:10445/metrics 有内容
□ Prometheus Targets 里 promdapter 为 UP
□ Grafana 探索里数据源是 Prometheus，且查询与 Prometheus 网页里一致
□ 时间范围选「最近 15 分钟」或「最近 5 分钟」
