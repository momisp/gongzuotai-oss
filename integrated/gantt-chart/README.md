# 项目排期甘特图

静态 Demo，支持多项目任务排期、甘特图展示与拖拽调整。

## 文件结构

```
├── index.html   # 页面结构（含「智能解析」按钮）
├── styles.css   # 样式
├── app.js       # 交互逻辑
└── README.md
```

## 本地打开

1. **四个文件放同一文件夹**
2. 双击 `index.html` 打开

或用本地服务：

```bash
npx serve .
```

## 功能

- 新建项目、添加任务、拖拽排期
- 单项目视图 / 多项目并排
- **智能解析**：粘贴排期文字或截图，自动生成甘特图

## 自检清单

| 检查项 | 通过标准 |
|--------|----------|
| 文件名 | 打开的是 `index.html`，不是 `prototype.html` |
| 同目录 | `styles.css`、`app.js` 与 `index.html` 在一起 |
| 按钮可见 | 工具栏「加载示例」右侧有「智能解析」 |
| 源码验证 | 右键查看源代码，能搜到 `id="openParseBtn"` |
| Network | F12 中 `app.js`、`styles.css` 均为 200 |

---

**一句话**：会话里截的 `prototype.html` 是旧版；最新版在四文件包里，「智能解析」在 `index.html` 工具栏最右侧。若仍看不到，99% 是打开了旧文件或 `app.js` 没存全——按上面 clone 分支取成套文件即可。
